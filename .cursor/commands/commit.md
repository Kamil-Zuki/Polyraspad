# Commit and Push

Apply the **13-commit** skill to stage, 13-commit, and push changes across the full monorepo.

## Invocation

Use `/13-commit` or run this command when the user asks to 13-commit, push, or save changes to git.

## What This Does

1. **Commit all repositories** — Every repo with changes gets its own 13-commit
2. **Push after each 13-commit** — Each child repo is pushed immediately after its 13-commit; root is pushed last

Execute the 13-commit skill workflow. Ensure **all** changed repos are 13-committed and pushed.
