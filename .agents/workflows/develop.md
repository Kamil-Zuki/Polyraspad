# Workflow: Разработка по плану (Develop Plan)

Этот workflow активируется командой `/develop`. Его цель — обеспечить строгую и методичную реализацию технических планов из папки `Docs/Plans/`.

## 🛠️ Шаги для AI-агента:

1. **Запрос плана (если не указан):** 
   Если пользователь просто написал `/develop`, спроси его: *"Какой план из папки `Docs/Plans/` мы будем реализовывать?"*. Если пользователь указал файл, переходи к шагу 2.

2. **Чтение контекста:**
   - Обязательно используй инструмент `view_file`, чтобы прочитать весь Markdown-файл указанного плана.
   - Если в плане есть ссылки на продуктовую документацию (например, `Docs/Product/`), прочитай и их для понимания бизнес-контекста.

3. **Инициализация задач (Planning Mode):**
   - Перейди в режим планирования.
   - Создай артефакт `task.md`, перенеся в него чек-лист (шаги) из прочитанного плана.

4. **Исполнение (Execution):**
   - Выполняй план строго шаг за шагом.
   - Делай атомарные изменения.
   - После каждого значимого шага обновляй артефакт `task.md`, отмечая галочки `[x]`.

5. **Верификация (Testing):**
   - Убедись, что написанный код компилируется. Запусти тесты, указанные в секции верификации плана или в глобальном файле `AGENTS.md`.

6. **Завершение и Архивация:**
   - Когда все пункты `task.md` выполнены, предложи пользователю переименовать файл плана, добавив префикс `(Done) ` (например, `Docs/Plans/(Done) 01_MVP.md`), чтобы переместить его в архив выполненных задач.
   - **Обязательно обнови файл `CHANGELOG.md` в корне проекта.** Если план завершен, перенеси выполненные задачи из секции `Planned` в секции `Added`, `Changed` или `Fixed` текущего релиза.
   - **Напомни про Global Versioning:** Если закрыт крупный этап, напомни пользователю поднять версию (SemVer) в `polyraspad-frontend/package.json` и поставить корневой Git Tag (см. правило 16 в `AGENTS.md`).
   - Сгенерируй артефакт `walkthrough.md` (Structured Session Log) с отчетом о проделанной работе. Отчет должен включать:
     - Список измененных файлов с кратким `diff summary`.
     - Результаты тестов и статус компиляции.
     - Оставшиеся открытые вопросы или технический долг, если есть.
