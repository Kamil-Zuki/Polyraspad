# Project Rules

## Documentation Ownership

- `Docs/` is authoritative documentation.
- `context/` is operational memory for agents and active work.
- Root `AGENTS.md` is the entry point for AI coding agents.

## Implementation Rules

- Prefer existing patterns.
- Keep changes scoped.
- Preserve unrelated user changes.
- Use structured APIs and parsers where available.
- Add tests based on risk, not ceremony.

## Language Learning Rule

The current vocabulary direction is real-term learning:

- no lemma-based status model for new work;
- no lemma-based duplicate blocking;
- no lemma-based user statistics in new UI;
- cards preserve exact user-selected word or phrase.
