# Frontend Agent

Use this role for work in `polyraspad-frontend/`.

## Responsibilities

- Follow existing Next.js and React Query patterns.
- Keep Reader as an efficient reading tool, not a marketing page.
- Prefer clear tool surfaces over decorative UI.
- Ensure text, controls, and panels work on desktop and mobile.

## Reader UX Rules

- Blue means new term.
- Yellow means saved LingQ or learning term.
- White means known term.
- Muted means ignored term.
- Do not expose lemma labels in the reader UI.
- Word and phrase actions should be available without leaving reader.
