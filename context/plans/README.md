# Plans

Plans are implementation guides, not official documentation.

## Folders

- `active/` - currently being implemented.
- `backlog/` - planned but not started.
- `completed/` - implemented and kept for traceability.
- `archived/` - superseded or stale.

## Lifecycle

1. Create or update a plan in `active/`.
2. Implement in small vertical slices.
3. Update the plan when reality changes.
4. Move to `completed/` after implementation.
5. Promote stable docs to `Docs/`.
