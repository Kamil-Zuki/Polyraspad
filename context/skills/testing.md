# Skill: Testing

Use this skill when adding or verifying behavior.

## Strategy

- Start with the narrowest test that proves the changed behavior.
- Add broader tests when API contracts, migrations, or shared flows change.
- For reviews, state residual risk if tests could not be run.

## LingQ Reader Minimum Cases

- separate statuses for real forms;
- exact-term duplicate behavior;
- phrase term behavior;
- page-turn known behavior;
- reader-created card preserves exact target text.
