# UX Principles

## Reader First

Language learning should happen inside the reader whenever possible.

Users should be able to:

- read;
- inspect a word or phrase;
- save a meaning;
- mark known;
- ignore;
- create a card;
- review saved terms;

without leaving the reading flow.

## Real Context

The app should preserve the sentence or phrase where the user first encountered a term.

## Real Forms

The UI should teach the form the user actually saw, not an abstract lemma.
