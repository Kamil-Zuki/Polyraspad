# Введение

Aggregator выступает **gRPC-клиентом** к внутренним микросервисам Polyraspad и **HTTP-клиентом** к внешним публичным API.

# 1. Downstream gRPC

| Интеграция | Base URL (config) | Proto | Сервисы |
| :--- | :--- | :--- | :--- |
| authorization-module | `AggregatorService:AuthorizationModuleBaseUrl` | `authorization.proto` | AuthService |
| VocabularyService | `AggregatorService:VocabularyServiceBaseUrl` | `vocabulary.proto` | Content, Card, Term, Text, Study, Analytics, Community, Subscription |
| MediaService | `AggregatorService:MediaServiceBaseUrl` | `media.proto` | MediaService |
| AgentService | `AggregatorService:AgentServiceBaseUrl` | `agent.proto` | AgentService |
| BillingService | `AggregatorService:BillingServiceBaseUrl` | `billing.proto` | BillingService |

Transport: **h2c** (HTTP/2 без TLS в Docker). Handler: `GrpcClientConfiguration.CreateSocketsHandler`.

Metadata на authenticated calls: `user_id`, `roles`.

# 2. External HTTP

| Интеграция | Использование | SR |
| :--- | :--- | :--- |
| OpenAI-compatible LLM | `Ai:BaseUrl` — chat completions, mining-draft | SR-AGG-AI-* |
| OpenAI/Mistral/espeak TTS | `Ai:TtsProvider` — generate-audio | SR-AGG-MEDIA-01 |
| MyMemory | POST translate | SR-AGG-INT-01 |
| Free Dictionary API | POST dictionary/lookup | SR-AGG-INT-01 |

# 3. Не используется на Aggregator

* Redis, RabbitMQ — stateless BFF
* WebSocket server — real-time не на шлюзе
