# Термины и определения

| Термин                            | Определение                                                                       |
| :-------------------------------- | :-------------------------------------------------------------------------------- |
| **Aggregator Service**            | Публичный BFF/API Gateway Polyraspad; REST наружу, gRPC внутрь                    |
| **BFF (Backend-for-Frontend)**    | Тонкий слой адаптации HTTP JSON ↔ gRPC без доменной логики                        |
| **Thin BFF**                      | Паттерн: parse, route, map — без собственной БД и бизнес-правил                   |
| **Downstream service**            | Внутренний микросервис (Vocabulary, Auth, Media, Agent, Billing)                  |
| **JWT Bearer**                    | Access token в заголовке `Authorization: Bearer …`, выданный authorization-module |
| **gRPC metadata**                 | Пары ключ-значение (`user_id`, `roles`) для identity propagation                  |
| **h2c**                           | HTTP/2 без TLS — транспорт gRPC внутри Docker network                             |
| **AI Proxy Key**                  | Shared secret `X-Ai-Proxy-Key` между Next.js BFF и Aggregator `/api/ai`           |
| **Term-first model**              | Обучение по точным формам/фразам; см. LingQ domain rules проекта                  |
| **ProjectTerm**                   | Термин проекта (WORD/PHRASE); персистится в VocabularyService, не в Aggregator    |
| **Rate limit policy auth-public** | 10 req/min/IP на публичные auth endpoints                                         |

См. также [[01 - Функциональная спецификация/Возможности сервиса/00 - Общая информация]] для SR-групп.
