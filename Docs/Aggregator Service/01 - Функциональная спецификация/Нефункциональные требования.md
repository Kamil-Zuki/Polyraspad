# Нефункциональные требования

| ID | Категория | Требование |
| :--- | :--- | :--- |
| NFR-AGG-01 | Availability | GET `/healthz` возвращает 200 `{ "status": "ok" }` |
| NFR-AGG-02 | Security | JWT secret ≥ 32 символов; placeholder secrets запрещены в production |
| NFR-AGG-03 | Security | CORS: explicit origins, без `*`; `AllowCredentials` для media |
| NFR-AGG-04 | Security | Provider LLM API keys только server-side (`Ai:ApiKey`) |
| NFR-AGG-05 | Performance | Stateless — горизонтальное масштабирование без sticky sessions |
| NFR-AGG-06 | Resilience | gRPC RpcException → осмысленные HTTP codes; daily summary — graceful default |
| NFR-AGG-07 | Observability | Structured logging в controllers (Serilog через ASP.NET Core) |
| NFR-AGG-08 | DevEx | Swagger UI в Development на `/swagger` |
| NFR-AGG-09 | Rate limiting | auth-public: 10 req/min/IP |
| NFR-AGG-10 | Transport | gRPC h2c внутри Docker; HTTPS termination на nginx |

Runtime: .NET 10, порт `5206` (host) / `5000` (container).
