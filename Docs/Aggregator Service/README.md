# Aggregator Service — документация микросервиса

Публичный **BFF / API Gateway** платформы Polyraspad. Принимает REST от браузера и Next.js, валидирует JWT локально, проксирует вызовы во внутренние микросервисы по gRPC (h2c).

## Эталон формата

- Полный образец: `(Done) Authorization Service/`
- Укороченный шаблон: `Шаблон документации микросервиса STEOS/`
- Правила агентов: `Docs/.cursor/rules/`

## Код

Реализация: `AggregatorService/` (submodule, .NET 10, порт `5206` / container `5000`).

## Отличия от domain-сервисов

- **Нет** собственной PostgreSQL, Redis, RabbitMQ
- **Нет** gRPC-сервера — только клиенты
- **Нет** WebSocket на шлюзе
- Персистентная модель данных — в `VocabularyService`, `authorization-module`, `MediaService`, `BillingService`, `AgentService`
