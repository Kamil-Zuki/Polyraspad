# ISSUE-004: Отсутствуют контрактные сущности (DTO) для Lessons и Autopilot в папке 03

## Тип

Пробел

## В двух словах

В функциональной спецификации `01` добавлены группы требований для уроков (Lessons) и автопилота (Autopilot), которые оперируют DTO-структурами (`Lesson`, `UserLessonProgress`, `GetDailyAutopilotPlanResponse`), но в папке `03 - Модель Данных` отсутствуют соответствующие описания этих API-контрактов на границе BFF шлюза.

## Где проблема

| Источник | Якорь | Что не сходится |
| :--- | :--- | :--- |
| 01 | `SR-AGG-LESSON-01..05`, `SR-AGG-AP-01` | Ссылаются на сущности уроков, прогресса и плана автопилота, не описанные в модели |
| 03 | `Entities - Список сущностей` | Нет упоминания контрактных DTO-сущностей для уроков и автопилота |

Путь к файлу (вторично): `03 - Модель Данных/01 - Основные сущности/Entities - Список сущностей микросервиса Aggregator Service.md`

## Доказательство

В индексе сущностей `Entities - Список сущностей микросервиса Aggregator Service.md` перечислены шесть групп API-контрактов, но группы для Lessons и Autopilot отсутствуют. На диске в каталоге `03/01 - Основные сущности/` нет файлов, описывающих структуры данных уроков и автопилота, с которыми взаимодействует клиент через BFF.

## Рекомендуемое действие

1. Создать файлы описания DTO-контрактов в папке `03/01 - Основные сущности/`:
   * `Entity - Уроки и прогресс - Lessons.md` (структуры `Lesson`, `UserLessonProgress` и `LessonWithProgress`).
   * `Entity - Автопилот дня - Autopilot.md` (структура `GetDailyAutopilotPlanResponse`).
2. Зарегистрировать их в общем списке сущностей `Entities - Список сущностей микросервиса Aggregator Service.md` в виде wikilinks.
3. Закрыть данную ISSUE после добавления описаний в папку `03`.
