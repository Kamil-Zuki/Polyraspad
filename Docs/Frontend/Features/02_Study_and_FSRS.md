# Фича: Система Повторений FSRS (Study & Review System)

**Статус:** Implemented  
**Связанный бекенд:** Vocabulary Service (`StudyService.StartStudySession`, `GetNextCard`, `SubmitReview`, `UndoReview`), inclusive (Python FSRS).

---

## 1. UX-сценарий (User Journey)

* **Шаг 1: Инициализация сессии.** Пользователь нажимает "Study Now" на Dashboard или выбирает колоду на странице `/decks`. Запускается `StartStudySession`.
* **Шаг 2: Просмотр лицевой стороны.** Отображается вопрос/контекст карточки (`FrontTemplate`). Пользователь пытается вспомнить перевод или целевое слово.
* **Шаг 3: Переворот карточки.** Пользователь нажимает `Space` или кликает по карточке. Появляется оборотная сторона (`BackTemplate`) и панели с 4 кнопками оценок.
* **Шаг 4: Выбор оценки FSRS.**
  * **Again (1):** Ошибка. Карточка уходит в Relearning.
  * **Hard (2):** Тяжело вспомнить. Небольшой прирост интервала.
  * **Good (3):** Нормально. Оптимальный интервал по целевому удержанию (90%).
  * **Easy (4):** Очень легко. Значительный прирост интервала.
* **Шаг 5: Опция отмены (Undo).** При случайном выборе ответа пользователь нажимает `Z` или кнопку "Undo", вызывая `UndoReview` и возвращая прошлую карточку.
* **Шаг 6: Завершение сессии.** После исчерпания очереди показывается экран подведения итогов сессии (количество повторенных карточек, сплит по оценкам и набранный XP).

## 2. Маршрутизация и Страницы (Routing)

* `src/app/study/page.tsx` (Client Component) — интерфейс сессии повторений.
* `src/app/study/summary/page.tsx` (Client Component) — экран итогов сессии.

---

## 3. Дерево компонентов (Component Architecture)

```
<StudyPage> (Client)
├── <StudyProgressBar> — прогресс текущей сессии (Due/Review/New counts)
├── <FlipCard> — интерактивная карточка с анимацией переворота (Framer Motion)
│   ├── <CardFront> — шаблонизированный фронт
│   └── <CardBack> — шаблонизированный бэк с выделением целевого слова
├── <RatingButtonGroup> — 4 кнопки с предрассчитанными интервалами (напр. "10m", "1d", "3d", "8d")
└── <StudyControls> — кнопки Undo, Suspend, Flag и аудио-воспроизведение
```

---

## 4. Интеграция с API (Data Fetching & BFF)

* **Чтение (Queries):**
  * `POST /api/v1/study/sessions/start` (`StudyService.StartStudySession`) — инициализация сессии.
  * `GET /api/v1/study/next-card` (`StudyService.GetNextCard`) — загрузка следующей карточки.
* **Мутации (Mutations):**
  * `POST /api/v1/study/review` (`StudyService.SubmitReview`) — отправка ответа пользователя.
  * `POST /api/v1/study/undo` (`StudyService.UndoReview`) — отмена последнего ответа.

---

## 5. Управление состоянием (State Management)

* **Локальное состояние:**
  * `isFlipped` (boolean): состояние переворота карточки.
  * `reviewHistory`: стек сохраненных ответов в текущей сессии для клиенского Undo.
* **Кэш React Query:**
  * Ключ `['study', 'session', deckId]` — кэш очереди карточек. При `SubmitReview` выводится следующая карточка из локального массива и инвалидируется статистика на Dashboard.
