# 00 — Общая Архитектура и Технологический Стек Frontend

Документ описывает архитектурный устройство, стек технологий, структуру директорий и ключевые паттерны веб-приложения **polyraspad-frontend**.

---

## 1. Технологический Стек

| Категория | Технологии / Библиотеки |
| :--- | :--- |
| **Фреймворк** | Next.js 16 (App Router only), React 19, TypeScript (strict mode). Node.js 22 runtime. |
| **Стилизация** | Tailwind CSS v4 (`@import "tailwindcss"` в `globals.css`), CSS design tokens (`bg-app-bg`, `bg-app-surface`, `text-brand-primary`, статусные цвета терминов). |
| **UI Primitives** | Radix UI (`@radix-ui/react-*`), `lucide-react`, `framer-motion`, `sonner` (тоасты), `tailwindcss-animate`. |
| **Управление данными & Кэш** | TanStack Query (`@tanstack/react-query`) v5 с Devtools для запросов и кэширования состояния сервера. |
| **Тестирование** | Vitest 4 + jsdom + React Testing Library + `@testing-library/user-event`. |

## 3. Провайдеры и Глобальное Состояние

Приложение обернуто в иерархию провайдеров в `src/app/layout.tsx`:

1. **QueryClientProvider (TanStack Query):** Кэш данных сервера, авто-рефетчинг при фокусе, optimistic updates.
2. **AuthContext (`contexts/AuthContext.tsx`):** Аутентификационный статус пользователя, токен, профиль.
3. **ProjectContext (`contexts/ProjectContext.tsx`):** Активный языковой проект (`activeProject`), переключение между проектами (`SourceLang` / `TargetLang`).
4. **OmnibarProvider (`contexts/OmnibarContext.tsx`):** Состояние глобального палитры команд `<Omnibar />`.

---

## 4. Глобальный Палитра Команд (`<Omnibar />`)

Компонент `<Omnibar />` смонтирован глобально на уровне `layout.tsx` и вызывается сочетанием клавиш **`Ctrl+K`** (или `Cmd+K` на macOS):

- **Быстрый переход (Navigation):** Переход в любой раздел (Dashboard, Reader, Study, Decks, Marketplace, Lessons, Settings).
- **Quick Add (`Add "word"`):** Быстрое создание карточки/термина из любой точки приложения.
- **Smart Filter:** Фильтрация по колодам и проектам.
- **AI Suggested Actions:** Быстрый запрос AI-объяснения или генерации примера.

## 5. BFF и Интеграция с Бекендом

- Клиентские компоненты выполняют запросы через REST API к `AggregatorService` (`NEXT_PUBLIC_API_URL`, дефолт `http://localhost:5000`).
- Запросы для AI-генерации проксируются через Next.js BFF маршруты `/api/ai/*` с использованием заголовочного ключа `X-Ai-Proxy-Key`.
