## **Введение**

Настоящий документ содержит описание gRPC интерфейсов микросервиса **Personal Vocabulary Service (PVS)**.

PVS выступает в роли внутреннего ресурса, инкапсулирующего логику управления контентом, алгоритмы обучения (FSRS) и социальные функции. Взаимодействие с внешним миром (клиентскими приложениями) осуществляется через **BFF (Backend for Frontend)**, который транслирует REST/GraphQL запросы в вызовы gRPC методов, описанных в данном документе.

Цель документа --- определить контракты (Messages, Services), коды ошибок и логику обработки для каждого метода, чтобы обеспечить корректную интеграцию с BFF.

Документ разработан на основе функциональных требований версии **7.0 (Golden Master)**.

## **1. ContentService (Проекты, Колоды, Настройки)**

Сервис отвечает за управление структурой контента: языковыми проектами и иерархией колод.

### **SR-STR-01: Создание проекта: CreateProject**

**Общая информация**

  ----------------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Сигнатура**           rpc CreateProject(CreateProjectRequest) returns (ProjectResponse)

  **Описание**            Создание нового языкового проекта. Метод инициализирует изолированное пространство для изучения, устанавливает дефолтные настройки алгоритма FSRS и создает корневую структуру.

  **Тип RPC**             Unary

  **Сообщение запроса**   CreateProjectRequest

  **Сообщение ответа**    ProjectResponse
  ----------------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

**Параметры сообщения (Request)**

  --------------------------------------------------------------------------------------
  Название параметра   Тип данных      Описание
  -------------------- --------------- -------------------------------------------------
  user_id              string (uuid)   Идентификатор пользователя (передается от BFF).

  title                string          Название проекта.

  source_lang          string          Код родного языка (ISO 639-1).

  target_lang          string          Код изучаемого языка (ISO 639-1).

  settings             SrsSettings     (Опционально) Кастомные настройки FSRS.
  --------------------------------------------------------------------------------------

**Логика обработки запроса**

- **Валидация:** Проверка кодов языков и длины названия.

- **Инициализация:** Выбор пресета настроек FSRS в зависимости от target_lang.

- **Сохранение:** Создание записи в таблице projects.

- **Bootstrapping:** Автоматическое создание системной колоды \"Inbox\" (Входящие).

- **Ответ:** Возвращает созданный объект проекта с ID.

**Статус-коды gRPC при ошибках**

  -----------------------------------------------------------------------------------------------------------
  Статус-код               Описание ошибки
  ------------------------ ----------------------------------------------------------------------------------
  **INVALID_ARGUMENT**     Некорректные коды языков или пустое название.

  **ALREADY_EXISTS**       Проект с таким названием уже существует у пользователя (если есть уникальность).

  **RESOURCE_EXHAUSTED**   Превышен лимит количества проектов для пользователя.
  -----------------------------------------------------------------------------------------------------------

### **SR-STR-01: Получение списка проектов: GetProjects**

**Общая информация**

  ----------------------- -------------------------------------------------------------------------------------------------------------------
  **Сигнатура**           rpc GetProjects(GetProjectsRequest) returns (GetProjectsResponse)

  **Описание**            Получение списка всех проектов пользователя с краткой статистикой. Используется для экрана выбора языка/предмета.

  **Тип RPC**             Unary

  **Сообщение запроса**   GetProjectsRequest

  **Сообщение ответа**    GetProjectsResponse
  ----------------------- -------------------------------------------------------------------------------------------------------------------

**Параметры сообщения (Request)**

  ------------------------------------------------------------------------
  Название параметра   Тип данных      Описание
  -------------------- --------------- -----------------------------------
  user_id              string (uuid)   Идентификатор пользователя.

  include_archived     bool            Флаг включения архивных проектов.
  ------------------------------------------------------------------------

**Логика обработки запроса**

- **Выборка:** Запрос к таблице projects по user_id.

- **Фильтрация:** Если include_archived = false, исключаются проекты с флагом is_archived = true.

- **Обогащение:** Извлечение кэшированной статистики (количество лемм) из JSONB поля stats.

- **Ответ:** Возвращает массив объектов Project.

**Статус-коды gRPC при ошибках**

  ----------------------------------------
  Статус-код     Описание ошибки
  -------------- -------------------------
  **INTERNAL**   Ошибка соединения с БД.

### **SR-STR-02: Получение деталей проекта: GetProjectDetails**

**Общая информация**

  ----------------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Сигнатура**           rpc GetProjectDetails(GetProjectDetailsRequest) returns (ProjectResponse)

  **Описание**            Получение полной информации о проекте, включая специфические настройки алгоритма FSRS (веса, retention). BFF использует этот метод при входе пользователя в проект.

  **Тип RPC**             Unary

  **Сообщение запроса**   GetProjectDetailsRequest

  **Сообщение ответа**    ProjectResponse
  ----------------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------------

**Параметры сообщения (Request)**

  ----------------------------------------------------------------------------------------------
  Название параметра   Тип данных      Описание
  -------------------- --------------- ---------------------------------------------------------
  user_id              string (uuid)   Идентификатор пользователя (для проверки прав доступа).

  project_id           string (uuid)   Идентификатор запрашиваемого проекта.
  ----------------------------------------------------------------------------------------------

**Логика обработки запроса**

- **Поиск:** Запрос к таблице projects по id.

- **Проверка прав:** Сервис сверяет project.user_id с переданным user_id. Если не совпадают --- возвращает ошибку (Security through obscurity).

- **Десериализация:** Поле fsrs_settings (JSONB) преобразуется в типизированную структуру Protobuf (SrsSettings).

- **Ответ:** Возвращает полный объект проекта.

**Статус-коды gRPC при ошибках**

  -------------------------------------------------------------------------------
  Статус-код             Описание ошибки
  ---------------------- --------------------------------------------------------
  **NOT_FOUND**          Проект не найден или принадлежит другому пользователю.

  **INVALID_ARGUMENT**   Некорректный формат UUID.
  -------------------------------------------------------------------------------

### **SR-STR-02: Обновление настроек проекта: UpdateProject**

**Общая информация**

  ----------------------- ---------------------------------------------------------------------------------------------------------------------------------------------------
  **Сигнатура**           rpc UpdateProject(UpdateProjectRequest) returns (ProjectResponse)

  **Описание**            Обновление метаданных (названия, архивации) и настроек алгоритма обучения. Позволяет пользователю адаптировать сложность SRS под конкретный язык.

  **Тип RPC**             Unary

  **Сообщение запроса**   UpdateProjectRequest

  **Сообщение ответа**    ProjectResponse
  ----------------------- ---------------------------------------------------------------------------------------------------------------------------------------------------

**Параметры сообщения (Request)**

**Логика обработки запроса**

- **Проверка прав:** Убедиться, что проект принадлежит user_id.

- **Валидация:** Если переданы настройки FSRS, проверить допустимые диапазоны (например, request_retention от 0.7 до 0.99).

- **Обновление:** Выполнить UPDATE соответствующих полей в таблице projects.

- **Синхронизация:** Обновить поле updated_at.

- **Ответ:** Возвращает обновленное состояние проекта.

**Статус-коды gRPC при ошибках**

  -------------------------------------------------------------------------------------
  Статус-код             Описание ошибки
  ---------------------- --------------------------------------------------------------
  **NOT_FOUND**          Проект не найден.

  **INVALID_ARGUMENT**   Недопустимые значения настроек (например, retention \> 1.0).
  -------------------------------------------------------------------------------------

### **SR-SETT-01: Получение настроек пользователя: GetUserSettings**

**Общая информация**

  ----------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Сигнатура**           rpc GetUserSettings(GetUserSettingsRequest) returns (UserSettingsResponse)

  **Описание**            Получение глобальных настроек пользователя (дневные лимиты, час смены суток) и текущего статуса серии (Streak). Реализует паттерн **Lazy Initialization**: если настройки еще не созданы, метод создает их с дефолтными значениями.

  **Тип RPC**             Unary

  **Сообщение запроса**   GetUserSettingsRequest

  **Сообщение ответа**    UserSettingsResponse
  ----------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

**Параметры сообщения (Request)**

  ------------------------------------------------------------------
  Название параметра   Тип данных      Описание
  -------------------- --------------- -----------------------------
  user_id              string (uuid)   Идентификатор пользователя.

  ------------------------------------------------------------------

**Логика обработки запроса**

- **Поиск:** Запрос к таблице user_settings по первичному ключу (user_id).

- **Ленивая инициализация:**

  - Если запись не найдена, сервис создает новую строку с дефолтными значениями:

    - rollover_hour = 4 (утра).

    - daily_goal_new = 20.

    - daily_goal_review = 100.

    - interface_language = \'en\'.

- **Ответ:** Возвращает объект настроек.

**Статус-коды gRPC при ошибках**

  --------------------------------------------------
  Статус-код             Описание ошибки
  ---------------------- ---------------------------
  **INVALID_ARGUMENT**   Некорректный формат UUID.

  **INTERNAL**           Ошибка базы данных.
  --------------------------------------------------

### **SR-STR-03: Получение дерева колод: GetDeckTree**

**Общая информация**

  ----------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Сигнатура**           rpc GetDeckTree(GetDeckTreeRequest) returns (GetDeckTreeResponse)

  **Описание**            Получение полной иерархической структуры (дерева) колод внутри указанного проекта. Метод оптимизирован для построения навигационного меню: возвращает только ID, названия и структуру вложенности, минимизируя объем передаваемых данных.

  **Тип RPC**             Unary

  **Сообщение запроса**   GetDeckTreeRequest

  **Сообщение ответа**    GetDeckTreeResponse
  ----------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

**Параметры сообщения (Request)**

**Логика обработки запроса**

- **Проверка доступа:** Убедиться, что проект принадлежит пользователю.

- **Выборка:** Сервис выполняет запрос к таблице decks с фильтром по project_id. Выбираются все колоды.

- **Построение дерева:**

  - Плоский список из БД преобразуется в дерево в памяти.

  - Колоды с parent_deck_id == NULL становятся корневыми узлами.

  - Остальные распределяются в списки children соответствующих родителей.

- 

- **Ответ:** Возвращает массив корневых узлов DeckTreeItem.

### **SR-VOC-01: Обновление колоды: UpdateDeck**

**Общая информация**

  ----------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Сигнатура**           rpc UpdateDeck(UpdateDeckRequest) returns (DeckResponse)

  **Описание**            Обновление метаданных колоды: названия, описания, обложки. Также позволяет перемещать колоду (изменять parent_deck_id) и менять настройки публичности/политики вкладов.

  **Тип RPC**             Unary

  **Сообщение запроса**   UpdateDeckRequest

  **Сообщение ответа**    DeckResponse
  ----------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------------------

**Параметры сообщения (Request)**

**Логика обработки запроса**

- **Проверка прав:** Убедиться, что user_id является владельцем (owner_id) колоды.

- **Защита контента (SR-MKT-04):**

  - Если меняется is_public на true, проверить поле license_type.

  - Если тип COMMERCIAL_DERIVATIVE (копия платного курса), запретить публикацию (вернуть ошибку).

- **Валидация перемещения:**

  - Если передан parent_deck_id, проверить, что новая родительская колода принадлежит тому же проекту.

  - Проверить на циклические ссылки (колода не может стать родителем самой себя).

- **Обновление:** Выполнить UPDATE в БД.

- **Ответ:** Возвращает обновленный объект Deck.

**Статус-коды gRPC при ошибках**

  -----------------------------------------------------------------------------------------------------------
  Статус-код              Описание ошибки
  ----------------------- -----------------------------------------------------------------------------------
  **NOT_FOUND**           Колода не найдена.

  **PERMISSION_DENIED**   Пользователь не является владельцем или пытается опубликовать защищенный контент.

  **INVALID_ARGUMENT**    Циклическая вложенность при перемещении.
  -----------------------------------------------------------------------------------------------------------

### **SR-BG-02: Удаление колоды: DeleteDeck**

**Общая информация**

  ----------------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------
  **Сигнатура**           rpc DeleteDeck(DeleteDeckRequest) returns (google.protobuf.Empty)

  **Описание**            Безвозвратное удаление колоды и всего её содержимого (карточек, вложенных колод). Инициирует процессы очистки медиа-файлов и защиты данных подписчиков.

  **Тип RPC**             Unary

  **Сообщение запроса**   DeleteDeckRequest

  **Сообщение ответа**    google.protobuf.Empty
  ----------------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------

**Параметры сообщения (Request)**

  ----------------------------------------------------------------------
  Название параметра   Тип данных      Описание
  -------------------- --------------- ---------------------------------
  user_id              string (uuid)   Идентификатор пользователя.

  deck_id              string (uuid)   Идентификатор удаляемой колоды.
  ----------------------------------------------------------------------

**Логика обработки запроса**

- **Проверка прав:** Убедиться, что user_id владелец.

- **Обработка публичности (SR-COL-08):**

  - Если is_public == true, проверить наличие активных подписчиков.

  - Если подписчики есть, инициировать фоновую задачу **Automatic Detachment** (копирование колоды подписчикам).

- **Сбор мусора (SR-BG-02):**

  - Собрать media_id всех карточек в этой колоде.

  - Отправить сообщение в очередь media-cleanup для удаления файлов из S3.

- **Удаление:**

  - Выполнить DELETE FROM decks. Благодаря каскадному удалению (ON DELETE CASCADE), все карточки и под-колоды удалятся автоматически.

  - Создать запись в таблице deleted_objects (Tombstone) для синхронизации удаления на мобильных клиентах.

- **Ответ:** Пустой успешный ответ.

**Статус-коды gRPC при ошибках**

  --------------------------------------------
  Статус-код              Описание ошибки
  ----------------------- --------------------
  **NOT_FOUND**           Колода не найдена.

  **PERMISSION_DENIED**   Недостаточно прав.
  --------------------------------------------
