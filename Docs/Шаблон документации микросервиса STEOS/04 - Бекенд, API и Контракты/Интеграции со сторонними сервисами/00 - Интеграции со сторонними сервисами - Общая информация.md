# Введение

Настоящий документ содержит описание методов API и протоколов взаимодействия с глобальным провайдером идентичности (STEOS ID), а также с внутренними микросервисами платформы, используемыми микросервисом **Authorization Service**.

Цель данных интеграций — обеспечить выполнение критических требований по безопасной аутентификации (OIDC Flow) и валидации ключей подписи (**SR-AUTH-OI-01**, **SR-AUTH-OI-02**), автоматическому онбордингу новых пользователей (**SR-AUTH-OI-03**), асинхронной терминации сессий при глобальных блокировках (**SR-AUTH-OI-04**), проверке прав доступа при маршрутизации контекста (**SR-AUTH-SM-02**) и конвертации гостевых ресурсов в постоянные (**SR-AUTH-SM-03**).

Документ предназначен для разработчиков, инженеров по безопасности и команды эксплуатации (DevOps). Документ разработан на основе анализа функциональных требований (SR-AUTH-xxx) и архитектурных решений (КАР-xxx) и описывает как внешние (IdP), так и внутренние межсервисные зависимости, необходимые для функционирования локального контура авторизации.
