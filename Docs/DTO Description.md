## **Введение**

Настоящий документ содержит описание Объектов Передачи Данных (DTO) для микросервиса **Personal Vocabulary Service (PVS)** --- ядра образовательной платформы, отвечающего за управление пользовательским контентом, процесс запоминания (SRS), социальное взаимодействие и монетизацию.

Цель данного документа --- чётко определить структуры данных (DTO), которые используются для взаимодействия между клиентскими приложениями (Web, Mobile, Browser Extension) и сервером по REST API.

Документ разработан на основе функциональных требований (версия 7.0 Golden Master) и схемы базы данных сервиса и предназначен для использования разработчиками и тестировщиками.

## **Общая структура API-запросов**

  --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Компонент**                           **Описание**
  --------------------------------------- ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Запрос (Request)**                    Описывает данные, которые клиент отправляет на сервер. Может быть как GET-запросом с параметрами в URL, так и POST/PUT-запросом с телом в формате JSON, структура которого определяется соответствующим Request DTO.

  **Успешный ответ (Success Response)**   Описывает данные, которые сервер возвращает клиенту в случае успешной обработки (HTTP-статус 2xx). Может содержать тело с данными (Response DTO) или быть пустым, подтверждая успех операции (SuccessResponseDto).

  **Ответ с ошибкой (Error Response)**    В случае любой ошибки API возвращает стандартизированный объект **ProblemDetails** (RFC 7807), который предоставляет унифицированную структуру для обработки ошибок на стороне клиента.
  --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

  -----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  Параметр                  Значение
  ------------------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Реализация сущности**   Deck

  **Назначение**            Облегченная версия DTO колоды, оптимизированная для построения иерархического дерева навигации (например, в боковом меню приложения и на странице Library). Содержит поля для отображения структуры, обложки, признака «скачано/куплено» и фильтрации (Мои / Скачанные / Публичные).

**Структура DTO DeckTreeItemDto**

**Ответ GET колоды (GET /api/Decks/{id}):** возвращает полные метаданные колоды и статистику карточек: id, title, description, parentDeckId, projectId, ownerId, coverImageUrl, isPublic, contributionPolicy, licenseType, forkedFromId, createdAt, cardCount, stats (newCardsCount, learningCardsCount, dueCardsCount, totalCardsCount). Используется на странице Library (настройки колоды, обложка, бейдж Purchased) и для совместимости с DeckResponseDto на клиенте.

### **DTO: DeckSubscriptionDto**

  -----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  Параметр                  Значение
  ------------------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Назначение**             Подписка пользователя на колоду. Используется в GET /api/subscriptions (список) и POST /api/subscriptions/{deckId} (ответ создания). Совпадает с контрактом фронтенда (DeckSubscriptionDto в types.ts).
  -----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

**Структура DTO DeckSubscriptionDto**

Поля: **id** (string, идентификатор подписки или deckId для списка), **userId** (string, UUID пользователя), **deckId** (string, UUID колоды), **lastSyncedVersion** (number), **subscribedAt** (string, ISO 8601 UTC), **lastAccessedAt** (string, ISO 8601 UTC), **deckTitle** (string, опционально — название колоды).

**Эндпоинты:** GET `/api/subscriptions` — массив DeckSubscriptionDto; POST `/api/subscriptions/{deckId}` — 201 Created, тело DeckSubscriptionDto; DELETE `/api/subscriptions/{deckId}` — 204 No Content (идемпотентно).

## **9. Синхронизация (Sync)**

В этом разделе описываются DTO для обеспечения работы **Offline-режима** и синхронизации данных между сервером и клиентскими устройствами (мобильными приложениями).

### **DTO: SyncRequestDto**

  ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  Параметр                  Значение
  ------------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Реализация сущности**   Service Logic

  **Назначение**            Запрос на получение изменений (Delta Sync). Клиент отправляет этот запрос при запуске приложения или восстановлении связи, чтобы получить только те данные, которые изменились на сервере с момента последнего сеанса. Реализует **SR-SNC-01**.
  ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

**Структура DTO SyncRequestDto**

**Пример JSON**

## Aggregator: автоматизация — джобы импорта (REST)

- **POST** `/api/automation/jobs` — тело `CreateAutomationJobDto`: `type` (поддерживается `IMPORT`), `projectId`, `deckId`, `itemsCount` (1–100, по умолчанию 25). Создаёт демо-карточки в колоде через gRPC BulkCreate. Ответ `AutomationJobDto`: `status` `COMPLETED` или `FAILED` (+`lastError`).
- **GET** `/api/automation/jobs/{id}` — состояние джоба (хранение в памяти процесса Aggregator).
