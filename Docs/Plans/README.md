# 📂 Папка технических планов (Implementation Plans)

Эта директория предназначена для хранения технических, пошаговых планов реализации конкретных фич. В отличие от `Docs/Product/` (где хранится бизнес-логика и стратегия), здесь лежат инструкции типа *Step-by-step* для AI-агента и фаундера.

## 🤖 Как AI-агент работает с этой папкой:
1. Агент **НЕ читает** файлы из этой папки автоматически при старте нового диалога (чтобы не перегружать системный контекст завершенными задачами).
2. Чтобы запустить выполнение плана, в начале нового диалога просто напишите агенту:
   > *"Реализуй план из файла `Docs/Plans/название_плана.md`"*
3. Внутри планов рекомендуется использовать markdown-ссылки на глобальную документацию из `Docs/Product/`, чтобы агент мог быстро подгрузить нужный бизнес-контекст.

## 📝 Структура типового плана:
- **Цель:** Кратко, что мы кодим.
- **Бизнес-контекст:** Ссылка на файл из `Docs/Product/`.
- **Шаги реализации (Checklist):** 
  - [ ] Шаг 1: `путь/к/файлу` - что именно изменить.
  - [ ] Шаг 2: ...
  - [ ] Шаг N: Тестирование (какую команду запустить).
