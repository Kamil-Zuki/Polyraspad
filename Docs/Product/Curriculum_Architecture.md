# Polyraspad Curriculum Architecture
## Структурированная Учебная Программа по Иностранным Языкам

**Версия:** 1.0  
**Дата:** 2026-07  
**Статус:** Основополагающий документ

---

## 1. Философия: Почему нужна Структура?

Текущий модуль уроков содержит 21 тему в произвольном порядке. Пользователь открывает список и не понимает:
- С чего начать?
- Что он уже знает?
- Что нужно пройти, чтобы достичь B2?

**English Grammar in Use** работает иначе. Книга — это не список упражнений, это **маршрут**. Каждая тема (unit) имеет место в общей карте знаний. Пользователь всегда понимает, где он находится и куда движется.

**Цель этого документа:** Определить полную структуру учебной программы Polyraspad, её уровни, темы и систему прогрессии — так, чтобы любой пользователь мог открыть платформу и ответить себе на вопрос: *"Я на уровне A2, мне осталось освоить 8 тем, чтобы перейти на B1."*

---

## 2. Система Уровней (CEFR)

Polyraspad использует международную шкалу CEFR (Common European Framework of Reference for Languages).

| Уровень | Название | Описание пользователя |
|---------|----------|----------------------|
| **A1** | Начинающий (Starter) | Понимает и использует самые базовые фразы. Может представиться. |
| **A2** | Элементарный (Elementary) | Понимает повседневные выражения. Общается на знакомые темы. |
| **B1** | Средний (Intermediate) | Справляется в большинстве ситуаций в стране языка. Описывает опыт. |
| **B2** | Выше среднего (Upper-Intermediate) | Понимает сложные тексты. Общается свободно и спонтанно. |
| **C1** | Продвинутый (Advanced) | Использует язык гибко для социальных, академических, профессиональных целей. |
| **C2** | Мастерство (Mastery) | Понимает практически всё. Выражается спонтанно и точно. |

> **MVP:** Платформа в первую очередь покрывает уровни **A1 → B2**. C1/C2 — в перспективе.

## 3. Полная Карта Учебной Программы

Каждый уровень разбит на **модули (Units)**. Модуль = одна конкретная тема. Для каждой темы есть:
- Теоретическая часть (материал урока)
- Интерактивная практика с ИИ-репетитором
- Упражнения на 4 навыка (R/L/W/S)

### Уровень A1 — Starter (12 модулей)

**Цель:** Научиться представлять себя, описывать базовые вещи, понимать простые инструкции.

| # | Тема | Ключевые конструкции | Навык |
|---|------|----------------------|-------|
| 1 | Глагол to be: am/is/are | I am, you are, she is | W, S |
| 2 | Это и то: this/that/these/those | This is my book | R, W |
| 3 | Артикли: a/an/the | a car, an apple, the sun | R, W |
| 4 | Местоимения и притяжательные | I/my, you/your, he/his | W, S |
| 5 | Present Simple: утверждение | I work, she works | W, S |
| 6 | Present Simple: отрицание и вопрос | Do you...? I don't... | W, S |
| 7 | Числа, даты, время | It's 3 o'clock / January 5th | L, S |
| 8 | Множественное число и исключения | cats, children, women | R, W |
| 9 | Глагол have/have got | I have a car / I've got... | W, S |
| 10 | Предлоги места: in/on/at/next to | The book is on the table | R, S |
| 11 | Прилагательные и порядок слов | a big red car | R, W |
| 12 | Глагол can/can't: способность | I can swim, she can't drive | W, S |

**Итого A1:** 12 уроков | ~6 часов практики с AI

## 4. Система Прогрессии и Разблокирования

### Логика Prerequisites (Зависимости)

Уроки не обязательно жестко блокированы, но система рекомендует порядок:

```
A1 (Завершен полностью)
       ↓
A2 (Открывается)
       ↓
B1 (Открывается)
       ↓
B2 (Открывается)
```

**Внутри уровня** — линейная прогрессия. Например, в B1 нельзя пройти урок 3 (Present Perfect vs Past Simple), пока не пройдены уроки 1 и 2.

**Опциональное пропускание:** Пользователь может пройти **Placement Test** при первом входе и начать с нужного уровня, не проходя всё с A1.

### Placement Test (Входное Тестирование)

При первом заходе в `/lessons`:
1. ИИ-агент задает 15-20 диагностических вопросов (progressive difficulty).
2. На основе ответов система определяет стартовый уровень.
3. Соответствующий уровень открывается с нужного урока.

## 5. Необходимые Изменения в Данных

### 5.1 Обновление Entity `Lesson`

```csharp
public class Lesson
{
    // Существующие поля...
    
    // Новые поля:
    public string CefrLevel { get; set; } = "A1"; // A1/A2/B1/B2/C1/C2
    public int OrderIndex { get; set; } = 0;       // Порядок внутри уровня (1-N)
    public string Module { get; set; } = "";        // Подгруппа внутри уровня (опционально)
    public Guid? UnlocksAfterLessonId { get; set; } // Prerequisite урок
    public string TargetSkills { get; set; } = "R,W"; // R/L/W/S через запятую
    public int EstimatedMinutes { get; set; } = 20; // Примерное время прохождения
}
```

### 5.2 Обновление `UserLessonProgress`

```csharp
public class UserLessonProgress
{
    // Существующие поля...
```

## 8. Связь с Автопилотом

Данная структура напрямую интегрируется в Autopilot:

- **Daily Mission** теперь будет предлагать следующий урок в очереди, а не случайный.
- **Skill Radar Chart** будет отображать прогресс не только по навыкам (R/L/W/S), но и по уровням CEFR.
- **Оркестратор** сможет строить персонализированный путь: *"Твой Speaking на уровне B1, а Grammar — A2. Сначала закроем Gap в Grammar, затем перейдем к Speaking практике уровня B1."*
