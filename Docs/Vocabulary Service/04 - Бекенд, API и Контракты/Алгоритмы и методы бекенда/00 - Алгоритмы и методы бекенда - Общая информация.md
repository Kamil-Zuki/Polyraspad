# Введение

Данный раздел описывает ключевые доменные алгоритмы, реализуемые бекендом микросервиса **Vocabulary Service**.

---

# 1. Список Ключевых Алгоритмов

| Алгоритм | Назначение | Описание |
| :--- | :--- | :--- |
| **FSRS v4 Scheduling** | Интервальные повторения | Алгоритм расчета стабильности (Stability), сложности (Difficulty) и даты следующего показа карточки на основе оценок пользователя (Again, Hard, Good, Easy). |
| **Text Analysis & Phrase Matching** | Токенизация и ридер | Алгоритм токенизации текста на слова и знак препинания, жадного сопоставления сохраненных фраз и определения статусов изученности (`NEW`, `SAVED`, `KNOWN`, `IGNORED`). |
| **Exact-Form Duplicates Check** | Проверка дубликатов | Алгоритм поиска существующих карточек в проекте на основе точной текстовой формы (`ProjectTerm`), исключающий созданий дублирующих карточек. |
| **Autopilot Daily Recommendations** | Автопилот дня | Вычисление приоритетных задач пользователя (Next Best Actions) на основе объемов долгов (backlog risk score) и дневных целей. |
