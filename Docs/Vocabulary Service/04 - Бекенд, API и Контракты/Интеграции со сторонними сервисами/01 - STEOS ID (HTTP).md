# Введение

Данный документ описывает синхронную интеграцию по протоколу HTTP/REST с глобальным провайдером идентичности — **STEOS ID**. Эта интеграция является фундаментом безопасности Authorization Service. Она реализует защищенный обмен авторизационных кодов на OIDC-токены, а также механизмы фонового поддержания доверия (скачивание публичных ключей JWKS и тихое серверное продление сессий).

# Общая информация

Обеспечение OIDC-аутентификации, валидации подписей JWT и поддержания жизненного цикла сессий. Authorization Service выступает здесь как `Relying Party` (RP) или `OIDC Client`.

| Параметр | Описание |
| :--- | :--- |
| **Версия API** | OAuth 2.1 / OpenID Connect 1.0 |
| **Название сервиса** | STEOS ID (Глобальный провайдер идентичности) |

# Доступ и аутентификация

Механизмы защиты Server-to-Server (S2S) взаимодействия между локальной Платформой и глобальным STEOS ID.

| Параметр | Описание |
| :--- | :--- |
| **Метод аутентификации** | Basic Authentication (`client_id` и `client_secret`) или mTLS для эндпоинта `/token`. Эндпоинт `/jwks.json` публичен. |
| **Хранение учетных данных** | `client_secret` хранится в **HashiCorp Vault** или Kubernetes Secrets и никогда не передается фронтенду. |
