# Интеграции: Внутренние события шины RabbitMQ

Данный документ содержит сведения о событиях шины сообщения между `VocabularyService` и другими компонентами платформы Polyraspad.

---

## 1. Публикуемые события
- `vocab.term.status_changed`: Публикуется при смене статуса точной формы слова для оптимизации индексации в ридере.
- `vocab.card.created`: Публикуется при создании новой карточки.
