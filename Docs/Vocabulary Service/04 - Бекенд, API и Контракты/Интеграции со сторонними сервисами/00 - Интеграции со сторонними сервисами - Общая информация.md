# Введение

Настоящий документ содержит обзор всех интеграций микросервиса **Vocabulary Service** со смежными внутренними микросервисами платформы Polyraspad.

`Vocabulary Service` взаимодействует с другими микросервисами по протоколу **gRPC** над h2c (HTTP/2 без шифрования во внутренней сети Compose/Kubernetes):

| Сервис | Протокол | Порт | Цель интеграции |
| :--- | :--- | :--- | :--- |
| **inclusive** (Python) | gRPC (`vocab.proto`) | `:40051` | NLP-токенизация/лемматизация (NLTK) и расчет FSRS интервалов/устойчивости |
| **MediaService** | gRPC (`media.proto`) | `:5121` | Генерация и проверка URL изображений и аудиофайлов карточек |
| **BillingService** | gRPC (`billing.proto`) | `:5127` | Проверка прав доступа и лимитов подписок на платные колоды (`UserEntitlement`) |
| **AgentService** | gRPC (`vocabulary.proto`) | `:5131` | Чтение словаря пользователя AI-ассистентом и выполнение действий с карточками |
