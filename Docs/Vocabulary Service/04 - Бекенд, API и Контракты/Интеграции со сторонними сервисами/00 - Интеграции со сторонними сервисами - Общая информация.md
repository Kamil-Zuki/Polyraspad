# Введение

Настоящий документ описывает внешние и межсервисные зависимости **Vocabulary Service** платформы Polyraspad.

Vocabulary — внутренний gRPC-домен: публичный REST/JWT — на **Aggregator Service**. Исходящие интеграции нужны для NLP/FSRS, медиа-URL и entitlements marketplace.

# 1. Список интеграций

| Интеграция | Протокол | Назначение |
| :--- | :--- | :--- |
| **inclusive** | gRPC | Токенизация / лемматизация; FSRS `ReviewCard` |
| **Media Service** | URLs / (опц. gRPC) | Object storage URLs для media в карточках и Reader Library |
| **Billing Service** | gRPC | Entitlements для marketplace / deck access |
| **Aggregator Service** | gRPC (входящий клиент) | Primary BFF caller |
| **Agent Service** | gRPC (входящий клиент) | Project-scoped AI tools |

Файлы `01 - External IdP (HTTP)` и `02 - External IdP (RabbitMQ)` — placeholders в дереве layout: Vocabulary **не** ходит во внешний IdP (identity из gRPC metadata).
