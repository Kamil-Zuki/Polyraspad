# Введение

Данный документ описывает структуры данных (DTO), относящиеся к группе Управления сессиями и контекстом (Session Management). Эти объекты предоставляют механизмы для безопасной передачи метаданных о текущем подключении пользователя (скрывая при этом сам Phantom Token), управления списком активных устройств, переключения рабочих пространств (Context Routing) и поддержания жизни сессии (Silent Refresh). 

Использование этих DTO позволяет Frontend-приложениям строить интерфейсы управления безопасностью ("Мои устройства") и переключать контексты без риска утечки чувствительных токенов.

# 1. Список DTO

В таблице ниже перечислены DTO, обеспечивающие управление жизненным циклом и контекстом локальных сессий.

| **Название DTO** | **Назначение** |
| :--- | :--- |

# DTO: SessionDto

## Контекст и назначение

Объект используется для представления информации об одном активном подключении (сессии) пользователя к Платформе. Он возвращается клиенту для отображения в настройках безопасности (раздел "Мои устройства"). Важнейшее свойство этого DTO — он **никогда** не содержит самого значения Phantom Token (Cookie) или OIDC-токенов.

**Назначение:** Ответ (Справочник / Сущность).
**Реализация сущности:** Таблица `authorized_sessions` и кэш Redis.

## Структура данных

Включает публичный идентификатор сессии (используемый для её отзыва), метаданные устройства и временные метки жизненного цикла.

| **Имя поля (JSON)** | **Тип данных** | **Описание** |
| :--- | :--- | :--- |
| `id` | `uuid` | Публичный идентификатор сессии (не путать со значением Cookie). |
| `ipAddress` | `string` | IP-адрес, с которого была инициирована сессия. |

## Пример работы (JSON)

Пример описания сессии пользователя, зашедшего с мобильного устройства.

```json
{
  "id": "a1b2c3d4-e5f6-7777-8888-9999aaaabbbb",
  "ipAddress": "192.168.1.15",
  "deviceFingerprint": "hash_8f7d6c...",
  "userAgent": "Safari Mobile 17.0 on iOS 17.2",
  "location": "Санкт-Петербург, Россия",
  "createdAt": "2026-03-25T10:00:00Z",
  "expiresAt": "2026-03-25T22:00:00Z",
  "isCurrent": false
}
```
