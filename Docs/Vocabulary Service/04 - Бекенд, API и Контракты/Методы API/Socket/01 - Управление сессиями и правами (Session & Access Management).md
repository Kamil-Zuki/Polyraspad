# WebSocket События: Синхронизация и Обновления Словаря

Данный документ описывает WebSocket-события real-time слоя **AggregatorService** для уведомлений пользователя об изменениях в словаре.

---

## 1. Список Событий

### `vocab.card_updated`
- **Описание:** Уведомляет открытые вкладки SPA о редактировании карточки или изменении ее FSRS-состояния.

### `vocab.sync_status`
- **Описание:** Информирует клиента о прогрессе процесса офлайн-синхронизации (`SyncData`).
