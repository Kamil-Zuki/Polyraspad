# Введение

Настоящий документ определяет роль real-time коммуникации (WebSocket) в системе Polyraspad для функций **Vocabulary Service**.

В Polyraspad WebSocket соединения удерживаются на уровне **AggregatorService (BFF)**. `VocabularyService` не держит прямого WSS-клиентского подключения, но отправляет внутренние события для уведомления клиетов (например, завершение длительных операций фонового импорта, результаты обработки аудио/медиа или прогресс sync).

---

# 1. Сценарии Real-time Уведомлений

| Событие | Назначение | Источник |
| :--- | :--- | :--- |
| `sync.delta_available` | Уведомление о появлении новых данных для оффлайн-клиентов | `SyncService` |
| `import.completed` | Уведомление о завершении импорта файлов колод (CSV/Anki) | `CardService` / Background job |
| `autopilot.updated` | Уведомление о пересчете плана автопилота | `AutonomyService` |
