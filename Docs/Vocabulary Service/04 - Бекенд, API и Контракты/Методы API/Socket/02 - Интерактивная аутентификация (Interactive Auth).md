# WebSocket События: Прогресс Импорта и Автопилот

Данный документ описывает WebSocket-события real-time слоя **AggregatorService** для уведомлений об импорте и автопилоте.

---

## 1. Список Событий

### `vocab.import_progress`
- **Описание:** Передает процент выполнения фонового импорта Anki/CSV файла в браузер.

### `vocab.autopilot_ready`
- **Описание:** Сигнализирует о готовности обновленного ежедневного плана автопилота.
