# REST API Aggregator BFF: Повторения, Уроки, Синхронизация и Маркетплейс

Данный документ описывает REST-эндпоинты **AggregatorService** для управления интервальными повторениями FSRS, уроками CEFR, оффлайн-синхронизацией и каталогом колод.

---

## 1. Интервальные Повторения (`/api/v1/study`)

| Метод | Эндпоинт | gRPC метод | Описание |
| :---: | :--- | :--- | :--- |
| `POST` | `/api/v1/study/sessions/start` | `StudyService.StartStudySession` | Старт новой учебной сессии по колоде |
| `GET` | `/api/v1/study/next-card` | `StudyService.GetNextCard` | Получение очередной карточки |
| `POST` | `/api/v1/study/review` | `StudyService.SubmitReview` | Отправка оценки FSRS (1-4) |
| `POST` | `/api/v1/study/undo` | `StudyService.UndoReview` | Отмена последнего ответа |

---

## 2. Учебный План и Уроки (`/api/v1/lessons`)

| Метод | Эндпоинт | gRPC метод | Описание |
| :---: | :--- | :--- | :--- |
| `GET` | `/api/v1/lessons` | `LessonService.GetLessons` | Список уроков и прогресс уровней CEFR |
| `POST` | `/api/v1/lessons/{id}/start` | `LessonService.StartLesson` | Старт урока и привязка потока AI-агента |
| `POST` | `/api/v1/lessons/{id}/complete` | `LessonService.CompleteLesson` | Завершение урока с фиксацией балла |
| `POST` | `/api/v1/lessons/placement` | `LessonService.SetPlacementLevel` | Прохождение Placement Test |

---

## 3. Синхронизация и AI-Инструменты

| Метод | Эндпоинт | gRPC метод | Описание |
| :---: | :--- | :--- | :--- |
| `POST` | `/api/v1/sync` | `SyncService.SyncData` | Запрос дельта-изменений по sync-токену |
| `POST` | `/api/v1/sync/batch-reviews` | `SyncService.BatchSubmitReviews` | Пакетная отправка офлайн-ответов |
| `POST` | `/api/v1/ai/generate-context` | `AIService.GenerateContext` | Генерация примера предложения с целевым словом |
| `POST` | `/api/v1/ai/explain-grammar` | `AIService.ExplainGrammar` | Объяснение грамматики для указанной фразы |

---

## 4. Маркетплейс и Подписки (`/api/v1/marketplace`)

| Метод | Эндпоинт | gRPC метод | Описание |
| :---: | :--- | :--- | :--- |
| `GET` | `/api/v1/marketplace/catalog` | `CommunityService.GetMarketplaceCatalog` | Поиск и фильтрация публичных колод |
| `GET` | `/api/v1/marketplace/products/{id}` | `CommunityService.GetProductDetails` | Карточка товара с превью заметок |
| `POST` | `/api/v1/marketplace/subscribe` | `SubscriptionService.Subscribe` | Подписка и скачивание колоды в библиотеку |
