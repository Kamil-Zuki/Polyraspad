# Введение

Данный документ описывает использование Redis в микросервисе **Vocabulary Service** (порт host **6379**).

Redis используется сервисом в качестве высокоскоростного кэша (Cache-Aside pattern) и хранилища оперативных очередей:
- Кэширование сформированного дерева колод (`GetDeckTree`) пользователя.
- Кэширование оперативных статистических показателей проекта.
- Кэширование временных сессий повторения (`StudySession`) для снижения нагрузки на PostgreSQL при интенсивном прохождении карточек.

---

# 1. Структура Ключей и TTL

| Назначение | Формат ключа | TTL |
| :--- | :--- | :--- |
| **Дерево колод** | `vocab:deck_tree:{user_id}:{project_id}` | 5 минут (или сброс при мутации) |
| **Сессия повторений** | `vocab:study_session:{session_id}` | 24 часа |
| **Кэш терминов** | `vocab:term_status:{project_id}:{term_text}` | 1 час |
