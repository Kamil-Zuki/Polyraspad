# Работа с RabbitMQ: Логирование и Экспорт

Данный документ описывает асинхронные задачи обработки данных и выгрузки экспорта словаря.

## 1. Экспорт и Импорт Словаря
- **Очередь:** `vocab:tasks:export`
- **Описание:** Асинхронный фоновый воркер формирует CSV/Anki package файл словаря пользователя и загружает готовый архив в `MediaService` (S3 MinIO).
