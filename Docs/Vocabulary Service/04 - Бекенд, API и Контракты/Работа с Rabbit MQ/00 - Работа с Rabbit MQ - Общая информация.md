# Введение

Данный документ описывает асинхронное взаимодействие микросервиса **Vocabulary Service** через событийно-ориентированную шину сообщений.

В текущей архитектуре синхронное межсервисное взаимодействие реализовано преимущественно поверх **gRPC**. RabbitMQ зарезервирован для фоновой публикации событий доменного слоя:
- `vocab.card.created` — создание новой карточки (для индексации или уведомления ассистента).
- `vocab.term.status_changed` — изменение статуса термина (для перерасчета статистики ридера).
- `vocab.deck.published` — публикация новой версии колоды в Marketplace.
