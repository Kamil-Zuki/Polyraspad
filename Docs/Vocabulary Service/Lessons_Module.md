# Модуль "Уроки" (Lessons) — Техническое Задание

## 1. Концепция
На данный момент уроки запускаются через хардкод-промпты на клиенте и ведутся в общем интерфейсе Agent Workspace. 
Цель нового модуля — создать структурированную систему курсов и уроков, где пользователь может изучать теорию (Markdown) и сразу же отрабатывать её на практике в изолированном диалоге с ИИ-репетитором (Study Copilot).

## 2. Архитектура данных

Данные модулей и уроков будут храниться в **VocabularyService** (поскольку он уже отвечает за учебный контент и карточки). В будущем, при масштабировании, возможно выделение в отдельный `StudyService`.

### Основные сущности

#### `Lesson` (Урок)
Шаблон урока, создаваемый администраторами.
- `Id` (UUID)
- `Title` (Название, напр. "Present Perfect")
- `Description` (Краткое описание для каталога)
- `Category` (Grammar, Vocabulary, Situational)
- `ContentMarkdown` (**Обязательная теоретическая база**: правила, таблицы, списки слов. Постоянно отображается в левой панели UI).
- `SystemPrompt` (Секретный промпт для Агента, задающий правила проверки этого конкретного урока).
- `Difficulty` (Уровень: A1, A2, B1...)

#### `UserLessonProgress` (Прогресс пользователя)
- `Id` (UUID)
- `UserId`
- `LessonId` (FK)
- `Status` (`NotStarted`, `InProgress`, `Completed`)
- `AgentThreadId` (FK к AgentService). Для каждого начатого урока создается **отдельный изолированный тред**, чтобы история урока не смешивалась с общим чатом.
- `StartedAt`
- `CompletedAt`

## 3. Пользовательский интерфейс (UI)

### 3.1 Страница каталога (`/lessons`)
- Динамическая сетка уроков, загружаемых с бэкенда (`VocabularyService`).
- Фильтры по категориям и уровню сложности.
- Индикаторы прогресса: "Пройдено", "В процессе", "Новое".

### 3.2 Рабочее пространство урока (`/lessons/[id]`)
Используется интерфейс **Split View (разделенный экран)**:
- **Левая часть (Теория):** Статичный контент урока (рендеринг `ContentMarkdown`). *Согласно требованиям, теория должна быть постоянно видимой.*
- **Правая часть (Практика):** Интерфейс чата, подключенный к `AgentThreadId` этого урока. ИИ (Study Copilot) ведет диалог, основываясь на `SystemPrompt` урока.

## 4. Сценарий использования (User Flow) и Завершение урока

1. Пользователь выбирает урок в каталоге и нажимает "Начать".
2. Бэкенд создает `UserLessonProgress` со статусом `InProgress` и запрашивает у `AgentService` новый `ThreadId` с передачей `SystemPrompt` урока.
3. Открывается `/lessons/[id]`. Слева отображается теория.
4. Агент присылает первое приветственное сообщение, вовлекая пользователя в практику.
5. Пользователь отвечает, происходит интерактивное обучение (ролевая игра, проверка перевода и т.д.).
6. **Завершение урока:** 
   - *Агент (AI) принимает решение о завершении урока самостоятельно.*
   - Когда Агент видит, что ученик успешно усвоил материал и прошел все проверки, он вызывает функцию Tool Calling `mark_lesson_completed()`.
7. Система меняет статус `UserLessonProgress` на `Completed`, и UI поздравляет пользователя, предлагая вернуться в каталог.
