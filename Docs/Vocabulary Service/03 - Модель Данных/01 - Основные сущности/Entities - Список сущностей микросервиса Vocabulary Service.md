# Список сущностей микросервиса Vocabulary Service

Документ содержит полный перечень доменных сущностей микросервиса **Vocabulary Service**, сгруппированных по функциональным модулям (Группам). Каждая группа детально расписана в отдельном документе.

Источник истины полей и таблиц — EF-модель и `VocabularyServiceContextModelSnapshot` (schema `internal`, кроме отдельных таблиц Curriculum без schema-prefix).

## Группа 1: [[Entity - Ядро Словаря - Vocabulary Core|Ядро Словаря (Vocabulary Core)]]
*Базовые доменные сущности для хранения пользовательского словаря, колод, заметок и генерации карточек интервального повторения.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Проект** | `Project` | Языковое пространство пользователя (`Title`, `SourceLang`, `TargetLang`, FSRS settings, stats). |
| **Колода** | `Deck` | Группа карточек с иерархией, политикой контрибуций и лицензией. |
| **Тип Заметки** | `NoteType` | Схема полей заметки (например, "Basic", "Cloze"). |
| **Поле Заметки** | `NoteField` | Определение конкретного поля (в т.ч. `FieldType = "tags"` как тип поля, без отдельной entity Tag). |
| **Шаблон Карточки** | `CardTemplate` | Правило генерации карточки из полей заметки. |
| **Заметка** | `Note` | Набор сырых данных, из которого генерируются карточки. |
| **Карточка** | `Card` | Конкретная интерактивная карточка для изучения. |
| **Прогресс Карточки (FSRS)** | `UserCardProgress` | Параметры FSRS (Stability, Difficulty, Due и т.д.). |

> **Нет в коде:** отдельные сущности `Tag` / `NoteTag`. Теги моделируются значением поля заметки (`NoteField.FieldType = "tags"`).

## Группа 2: [[Entity - Лингвистическая Модель и NLP - Linguistics & NLP|Лингвистическая модель и NLP (Linguistics & NLP)]]
*Сущности ридера (LingQ-модель). Статусы и дубликаты опираются на точные формы (`ProjectTerm`), не на леммы.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Термин Проекта** | `ProjectTerm` | Уникальное слово или фраза в проекте (`WORD` / `PHRASE`). |
| **Статус Термина** | `UserTermStatus` | Статус изучения (`NEW`, `SAVED`, `KNOWN`, `IGNORED`; legacy `LINGQ`/`LEARNING` → API `SAVED`). |
| **Лемма Проекта** | `ProjectLemma` | Legacy-сущность леммы; продуктовая модель term-first (см. AGENTS.md). |

## Группа 3: [[Entity - Обучение и Учебный План - Curriculum & Study|Обучение и Учебный План (Curriculum & Study)]]
*Учебный план CEFR, AI-уроки и логи интервальных повторений.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Урок** | `Lesson` | Урок глобальной программы с `SystemPrompt`, контентом и CEFR-метаданными. |
| **Прогресс Урока** | `UserLessonProgress` | Статус прохождения (`LessonStatus` enum), score, thread агента. |
| **Прогресс Уровня CEFR** | `UserCefrProgress` | Агрегат по уровню: completed/total lessons, `IsLevelCompleted`. |
| **Учебная Сессия** | `StudySession` | Сессия прохождения карточек. |
| **Лог Повторений** | `ReviewLog` | История ответов для FSRS (`AnswerValidationResult` — jsonb). |

## Группа 4: [[Entity - Активность и Оценка Навыков - Activity & Assessment|Активность и Оценка Навыков (Activity & Assessment)]]
*Ежедневная активность по навыкам, shadowing, срезы оценки и прогресс чтения книг.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Тип Навыка** | `SkillType` | Справочник навыков с дневными нормами. |
| **Активность по Навыкам** | `UserSkillActivity` | Ежедневное накопление по навыку. |
| **Прогресс по Навыкам** | `UserSkillProgress` | Долгосрочный прогресс по навыку. |
| **Прогресс Чтения Книги** | `UserBookProgress` | Позиция чтения по внешнему `BookId` (MediaService). |
| **Попытка Shadowing** | `ShadowingAttempt` | Запись попытки повторения предложения (EF; отдельного gRPC CRUD нет). |
| **Лог Оценки Навыка** | `SkillAssessmentLog` | Результаты срезов уровня от AI. |

> **Нет в коде:** `GrammarTopic`, `UserGrammarProgress`. Объяснение грамматики — RPC `ExplainGrammar` без persistence справочника тем.

## Группа 5: [[Entity - Магазин Колод и Сообщество - Marketplace & Community|Магазин Колод и Сообщество (Marketplace & Community)]]
*Публикация колод, подписки, версии, отзывы и контрибуции.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Профиль Автора** | `AuthorProfile` | Профиль создателя публичных колод. |
| **Продукт** | `Product` | Публичная колода в каталоге. |
| **Отзыв на Продукт** | `ProductReview` | Оценка и текстовый отзыв. |
| **Вклад (Контрибуция)** | `Contribution` | Предложение изменений; `Type`: `EDIT` / `ADD` / `DELETE`. |
| **Подписка на Колоду** | `DeckSubscription` | Подписка пользователя на колоду. |
| **Версия Колоды** | `DeckVersion` | История версий колоды. |

## Группа 6: [[Entity - Системные Сущности и Настройки - System & Settings|Системные сущности и Настройки (System & Settings)]]
*Настройки, доступ к колодам и журнал удалений для sync.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Настройки Пользователя** | `UserSetting` | Цели, streak, язык UI, rollover (дефолты целей: New=20, Review=100). |
| **Доступ к Колоде** | `UserEntitlement` | Право доступа к колоде (`FREE`/`PURCHASE`/`PROMO`/`CONTRIBUTION`); SaaS-лимиты — в BillingService. |

## Группа 7: [[Entity - Документы и Ридер - Documents & Reader|Прогресс чтения (Reader Progress)]]
*В Vocabulary Service нет EF-сущностей Document/Chapter. Библиотека книг — MediaService; локально хранится только прогресс чтения.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Прогресс Чтения Книги** | `UserBookProgress` | (также в Группе 4) Внешний `BookId` + позиция/процент в рамках проекта. |

> **Нет в коде:** `Document`, `DocumentChapter`, `DocumentTermCount`.
