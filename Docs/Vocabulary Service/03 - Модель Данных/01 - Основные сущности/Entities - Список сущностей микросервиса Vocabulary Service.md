## Группа 1: Ядро Словаря (Vocabulary Core)
*Базовые доменные сущности для хранения пользовательского словаря, колод, заметок и генерации карточек интервального повторения.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Проект** | `Project` | Языковое пространство пользователя (целевой и родной языки). |
| **Колода** | `Deck` | Группа карточек, поддерживающая древовидную вложенность. |
| **Заметка** | `Note` | Набор сырых данных (слово, перевод, пример), из которого генерируются карточки. |
| **Тип Заметки** | `NoteType` | Схема полей заметки (например, "Basic", "Cloze"). |
| **Поле Заметки** | `NoteField` | Определение конкретного поля (например, "Word", "Translation"). |
| **Шаблон Карточки** | `CardTemplate` | Правило генерации карточки из полей заметки. |
| **Карточка** | `Card` | Конкретная интерактивная карточка для изучения. |
| **Прогресс Карточки (FSRS)** | `UserCardProgress` | Текущие параметры алгоритма FSRS (Stability, Difficulty, Due date) для карточки. |

## Группа 2: Лингвистическая модель и NLP (Linguistics & NLP)
*Сущности, обслуживающие ридер (LingQ-модель). Отвечают за хранение статусов слов и фраз в текстах.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Термин Проекта** | `ProjectTerm` | Уникальное слово или словосочетание в рамках проекта. |
| **Статус Термина** | `UserTermStatus` | Статус изучения слова пользователем (`NEW`, `SAVED`, `KNOWN`, `IGNORED`) и его уровни по шкалам навыков. |
| **Лемма Проекта** | `ProjectLemma` | Словарная форма (лемма) для группы словоформ изучаемого языка. |

## Группа 3: Обучение и Учебный План (Curriculum & Study)
*Сущности для ведения пользователя по учебному плану (CEFR), проведения AI-уроков и фиксации результатов.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Урок** | `Lesson` | Урок в глобальной программе обучения с системным AI-промптом. |
| **Прогресс Урока** | `UserLessonProgress` | Статус прохождения урока (`Completed`, `ScorePercent`, ссылка на AI-чат). |
| **Прогресс Уровня CEFR** | `UserCefrProgress` | Агрегированный статус прохождения уровней (A1, A2, B1...). |
| **Учебная Сессия** | `StudySession` | Сессия прохождения карточек (карточки на повторение). |
| **Лог Повторений** | `ReviewLog` | История ответов пользователя на карточки для тренировки модели FSRS. |

### Детальное описание сущностей Учебного Плана

#### Lesson
`Lesson` — это заранее заданный урок в глобальной программе обучения. Уроки разбиты по уровням CEFR и имеют строгую последовательность (в рамках UI, но не жестко в БД, за исключением `UnlocksAfterLessonId`).

**Поля:**
- `Id` (Guid, PK)
- `Title` (string) — название урока (например, "Greetings").
- `Description` (string) — описание урока.
- `CefrLevel` (string) — уровень урока (например, "A1", "B2").
- `OrderIndex` (int) — порядковый номер урока внутри уровня.
- `SystemPromptTemplate` (string) — системный промпт для ИИ, который будет проводить урок.
- `UnlocksAfterLessonId` (Guid?) — если задан, этот урок недоступен до прохождения указанного.

#### UserLessonProgress
`UserLessonProgress` — связующая сущность, фиксирующая прогресс конкретного пользователя по конкретному уроку.

**Поля:**
- `UserId` (Guid, PK, FK to User)
- `LessonId` (Guid, PK, FK to Lesson)
- `Status` (Enum: `NotStarted`, `InProgress`, `Completed`)
- `ScorePercent` (int) — процент успешности прохождения урока (0-100), заполняется ИИ в конце.
- `TimeSpentSeconds` (int) — сколько секунд пользователь потратил на урок.
- `StartedAt` (DateTime)
- `CompletedAt` (DateTime?)
- `AgentThreadId` (Guid?) — идентификатор чат-сессии в `AgentService`, где проходит урок.

#### UserCefrProgress
`UserCefrProgress` — агрегированная сущность, отражающая статус конкретного уровня CEFR для пользователя. Обновляется автоматически при завершении уроков (`UpsertCefrProgressAsync`).

**Поля:**
- `UserId` (Guid, PK, FK to User)
- `Level` (string, PK) — уровень (например, "A1").
- `Status` (Enum: `Locked`, `InProgress`, `Completed`) — статус прохождения уровня.
  - `Locked` — предыдущий уровень не пройден, этот закрыт (на уровне UI).
  - `InProgress` — пользователь начал хотя бы один урок уровня.
  - `Completed` — все уроки уровня успешно завершены (Status = Completed).
- `CompletedLessonsCount` (int) — количество завершенных уроков.
- `TotalLessonsCount` (int) — общее количество уроков в уровне.

#### Связь сущностей
```mermaid

    UserLessonProgress }o--|| User(External) : belongs_to
    UserCefrProgress }o--|| User(External) : belongs_to
    
    Lesson }|--|| UserCefrProgress : aggregates_into
```

## Группа 4: Активность и Оценка Навыков (Activity & Assessment)
*Сущности для отслеживания ежедневных показателей (минут чтения, выполненных упражнений) и результатов периодических тестов.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Тип Навыка** | `SkillType` | Справочник навыков (`reading`, `listening`...) с дневными нормами выполнения. |
| **Активность по Навыкам** | `UserSkillActivity` | Ежедневное накопленное значение активности по конкретному навыку. |
| **Лог Оценки Навыка** | `SkillAssessmentLog` | Результаты срезов уровня владения навыками от AI. |

## Группа 5: Магазин Колод и Сообщество (Marketplace & Community)
*Сущности для публикации колод в общий доступ, подписки и синхронизации версий.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Профиль Автора** | `AuthorProfile` | Профиль создателя публичных колод (био, социальные ссылки, бейджи). |
| **Продукт** | `Product` | Публичная колода в каталоге (цена, метаданные, статистика скачиваний). |
| **Отзыв на Продукт** | `ProductReview` | Оценка и текстовый отзыв покупателя о колоде. |
| **Вклад (Контрибуция)** | `Contribution` | Публикация новой версии колоды в магазин. |
| **Подписка на Колоду** | `DeckSubscription` | Связь пользователя с колодой из магазина для скачивания. |
| **Версия Колоды** | `DeckVersion` | История изменений структуры колоды для обновлений. |

## Группа 6: Системные сущности и Настройки (System & Settings)
*Служебные сущности для хранения конфигураций и синхронизации данных.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Настройки Пользователя** | `UserSetting` | Различные параметры интерфейса (например, авто-пометка слов известными). |

| **Удаленный Объект** | `DeletedObject` | Журнал удалений для корректной оффлайн-синхронизации клиентов. |
