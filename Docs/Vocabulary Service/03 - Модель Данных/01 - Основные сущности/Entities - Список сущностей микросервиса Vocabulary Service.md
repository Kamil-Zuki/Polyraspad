## Группа 1: [[Entity - Ядро Словаря - Vocabulary Core|Ядро Словаря (Vocabulary Core)]]
*Базовые доменные сущности для хранения пользовательского словаря, колод, заметок и генерации карточек интервального повторения.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Проект** | `Project` | Языковое пространство пользователя (целевой и родной языки). |
| **Колода** | `Deck` | Группа карточек, поддерживающая древовидную вложенность. |
| **Тип Заметки** | `NoteType` | Схема полей заметки (например, "Basic", "Cloze"). |
| **Поле Заметки** | `NoteField` | Определение конкретного поля (например, "Word", "Translation"). |
| **Шаблон Карточки** | `CardTemplate` | Правило генерации карточки из полей заметки. |
| **Заметка** | `Note` | Набор сырых данных (слово, перевод, пример), из которого генерируются карточки. |
| **Карточка** | `Card` | Конкретная интерактивная карточка для изучения. |
| **Прогресс Карточки (FSRS)** | `UserCardProgress` | Текущие параметры алгоритма FSRS (Stability, Difficulty, Due date) для карточки. |

## Группа 2: [[Entity - Лингвистическая Модель и NLP - Linguistics & NLP|Лингвистическая модель и NLP (Linguistics & NLP)]]
*Сущности, обслуживающие ридер (LingQ-модель). Отвечают за хранение статусов слов и фраз в текстах.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Термин Проекта** | `ProjectTerm` | Уникальное слово или словосочетание в рамках проекта. |
| **Статус Термина** | `UserTermStatus` | Статус изучения слова пользователем (`NEW`, `SAVED`, `KNOWN`, `IGNORED`). |
| **Лемма Проекта** | `ProjectLemma` | Словарная форма (лемма) для группы словоформ изучаемого языка. |

## Группа 3: [[Entity - Обучение и Учебный План - Curriculum & Study|Обучение и Учебный План (Curriculum & Study)]]
*Сущности для ведения пользователя по учебному плану (CEFR), проведения AI-уроков и фиксации результатов.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Урок** | `Lesson` | Урок в глобальной программе обучения с системным AI-промптом. |
| **Прогресс Урока** | `UserLessonProgress` | Статус прохождения урока (`Completed`, `ScorePercent`, ссылка на AI-чат). |
| **Прогресс Уровня CEFR** | `UserCefrProgress` | Агрегированный статус прохождения уровней (A1, A2, B1...). |
| **Учебная Сессия** | `StudySession` | Сессия прохождения карточек (карточки на повторение). |
| **Лог Повторений** | `ReviewLog` | История ответов пользователя на карточки для тренировки модели FSRS. |

## Группа 4: [[Entity - Активность и Оценка Навыков - Activity & Assessment|Активность и Оценка Навыков (Activity & Assessment)]]
*Сущности для отслеживания ежедневных показателей (минут чтения, выполненных упражнений) и результатов периодических тестов.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Тип Навыка** | `SkillType` | Справочник навыков (`reading`, `listening`...) с дневными нормами выполнения. |
| **Активность по Навыкам** | `UserSkillActivity` | Ежедневное накопленное значение активности по конкретному навыку. |
| **Прогресс по Навыкам** | `UserSkillProgress` | Постоянный долгосрочный прогресс по навыку: уровень, суммарная активность. |
| **Прогресс Чтения Книги** | `UserBookProgress` | Отслеживание позиции и процента прочтения конкретной книги/документа в ридере. |
| **Попытка Shadowing** | `ShadowingAttempt` | Попытка пользователя повторить предложение вслух (запись и оценка). |
| **Лог Оценки Навыка** | `SkillAssessmentLog` | Результаты срезов уровня владения навыками от AI. |

## Группа 5: [[Entity - Магазин Колод и Сообщество - Marketplace & Community|Магазин Колод и Сообщество (Marketplace & Community)]]
*Сущности для публикации колод в общий доступ, подписки и синхронизации версий.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
| **Профиль Автора** | `AuthorProfile` | Профиль создателя публичных колод (био, социальные ссылки, бейджи). |
| **Продукт** | `Product` | Публичная колода в каталоге (цена, метаданные, статистика скачиваний). |
| **Отзыв на Продукт** | `ProductReview` | Оценка и текстовый отзыв покупателя о колоде. |
| **Вклад (Контрибуция)** | `Contribution` | Предложение изменений или публикация новой версии карточки/колоды. |
| **Подписка на Колоду** | `DeckSubscription` | Связь пользователя с колодой из магазина для скачивания. |
| **Версия Колоды** | `DeckVersion` | История изменений структуры колоды для обновлений. |

## Группа 6: [[Entity - Системные Сущности и Настройки - System & Settings|Системные сущности и Настройки (System & Settings)]]
*Служебные сущности для хранения конфигураций и синхронизации данных.*

| Сущность | Класс C# | Описание |
| :--- | :--- | :--- |
