# Введение

Глоссарий терминов микросервиса **Vocabulary Service** платформы Polyraspad.

# Назначение и цель документа

Единый язык для разработчиков, QA и аналитиков при описании словаря, ридера, FSRS и Marketplace.

---

# Ключевые понятия и сущности

| Термин | Описание |
| :--- | :--- |
| **Project** | Языковое пространство пользователя (`Title`, `SourceLang`, `TargetLang`). |
| **ProjectTerm** | Точная словоформа или фраза (`WORD` / `PHRASE`); основа статусов и дубликатов (term-first). |
| **UserTermStatus** | Статус термина пользователя: `NEW`, `SAVED`, `KNOWN`, `IGNORED`. |
| **Note / Card** | Заметка с полями и сгенерированная из шаблона учебная карточка. |
| **UserCardProgress** | FSRS-состояние карточки (Stability, Difficulty, Due…). |
| **Deck** | Колода карточек; может быть публичной / fork / marketplace. |
| **UserBookProgress** | Прогресс чтения книги по внешнему `BookId` (MediaService). |
| **inclusive** | Python gRPC-сервис: FSRS review и NLP (tokenization). |
| **FSRS** | Free Spaced Repetition Scheduler — алгоритм интервального повторения. |
| **CEFR / Lesson** | Учебный план и уроки с прогрессом `UserLessonProgress`. |

# Процессы

| Термин | Описание |
| :--- | :--- |
| **Normalize term** | `trim` + lower + схлопывание пробелов (`TermNormalizer`); пунктуация не удаляется. |
| **Capture** | Создание карточки/термина из выделенного текста с проверкой дубликатов. |
| **BulkMarkKnown** | Пакетная пометка терминов `KNOWN` (в т.ч. page-turn на клиенте). |
| **Study session** | Сессия очереди New/Learning/Review с SubmitReview через inclusive. |

# Паттерны

| Термин | Описание |
| :--- | :--- |
| **Term-first** | Статусы, дубликаты и карточки опираются на точные формы, не на леммы. |
| **Thin BFF** | Публичный REST — Aggregator; Vocabulary — gRPC domain. |
