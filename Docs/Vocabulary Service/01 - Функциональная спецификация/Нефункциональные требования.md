# Введение

Нефункциональные требования к микросервису **Vocabulary Service** — ядру словаря, FSRS, ридера и Marketplace платформы Polyraspad.

# 1. Назначение документа

## 1.1 Цель документа

Зафиксировать ожидания по качеству:

* Корректность term-first инвариантов (точные формы, дубликаты, статусы);
* Предсказуемая latency gRPC для study queue и AnalyzeText;
* Надёжность интеграции с `inclusive` (FSRS/NLP) и MediaService;
* Согласованность данных при SyncData / offline tombstones;
* Безопасность: авторизация через metadata `user_id` от Aggregator, без хранения credentials.

## 1.2 Область применения

| Компонент | Ответственность |
| :--- | :--- |
| **VocabularyService** | EF Core / PostgreSQL domain, gRPC API |
| **inclusive** | FSRS и NLP по gRPC |
| **MediaService** | Бинарные медиа и Reader Library books |
| **BillingService** | SaaS entitlements (не marketplace deck access) |

## 1.3 Определения

| Термин | Описание |
| :--- | :--- |
| **API Gateway (Aggregator)** | Публичный REST BFF; вызывает Vocabulary по gRPC. |
| **h2c** | Plaintext HTTP/2 внутри Docker-сети. |
