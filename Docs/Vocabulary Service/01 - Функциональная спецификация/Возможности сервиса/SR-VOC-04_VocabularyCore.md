# SR-VOC-04: Ядро Словаря (Vocabulary Core)

## Описание
Данный раздел описывает функциональные требования к управлению пользовательскими проектами, иерархией колод, процессом создания заметок и генерации карточек, а также работой алгоритма интервального повторения FSRS.

---

## Возможности данного раздела

| Код | Название и Описание |
| :--- | :--- |
| **SR-VOC-CORE-01** | **Изоляция проектов (Project Isolation):** Изоляция всех пользовательских данных (колод, карточек, прогресса) в рамках языкового проекта. |
| **SR-VOC-CORE-02** | **Вложенные колоды (Nested Decks):** Организация карточек в колоды с поддержкой неограниченной древовидной вложенности. |
| **SR-VOC-CORE-03** | **Генерация карточек по шаблонам (Card Generation):** Создание заметок с динамическими полями и автогенерация карточек на основе шаблонов отображения. |
| **SR-VOC-CORE-04** | **Интервальное повторение FSRS (FSRS Scheduling):** Расчет параметров удержания в памяти (Due, Stability, Difficulty) по алгоритму FSRS-4.5 при каждом ответе. |
| **SR-VOC-CORE-05** | **Тегирование заметок (Note Tagging):** Привязка тегов к заметкам для фильтрации и создания сессий повторений по тегам. |

---

# Детальная спецификация требований

## SR-VOC-CORE-01: Изоляция проектов {#SR-VOC-CORE-01}
### 1. Цель и ключевые принципы
- **Целевая языковая изоляция:** Проект представляет собой замкнутое пространство для пары (изучаемый язык + родной язык).
- **Отсутствие пересечений:** Слово в проекте "Английский -> Русский" никак не связано со словом в проекте "Испанский -> Русский".

### 2. Высокоуровневое описание
Пользователь может создать несколько проектов. В каждый момент времени активен только один проект (`IsActive = true`). Все запросы к словарю, читалке и ИИ-тьютору неявно фильтруются по `ProjectId` текущего активного проекта.

---

## SR-VOC-CORE-02: Вложенные колоды {#SR-VOC-CORE-02}
### 1. Цель и ключевые принципы
- **Иерархическая структура:** Возможность создавать подколоды (например, "Испанский -> Глаголы -> Неправильные").
- **Каскадное повторение:** Запуск изучения родительской колоды включает в себя карточки из всех дочерних подколод.

---

## SR-VOC-CORE-03: Генерация карточек по шаблонам {#SR-VOC-CORE-03}
### 1. Цель и ключевые принципы
- **Note-Card separation:** Пользователь создает одну заметку (Note), содержащую данные полей (например, "Word", "Translation", "Audio").
- **Автогенерация:** Из одной заметки генерируются одна или несколько карточек (Card) по шаблонам (например, шаблон "Прямой: Слово -> Перевод" и "Обратный: Аудио -> Слово").

---

## SR-VOC-CORE-04: Интервальное повторение FSRS {#SR-VOC-CORE-04}
### 1. Цель и ключевые принципы
- **Математическая модель памяти:** Опора на параметры `Stability` (устойчивость) и `Difficulty` (сложность).
- **Четыре оценки:** При прохождении карточки пользователь оценивает свой ответ: `Again` (1), `Hard` (2), `Good` (3), `Easy` (4).
- **Пересчет интервала:** Система отправляет параметры в Python-микросервис `inclusive` для расчета даты следующего показа (`Due`).

---

## SR-VOC-CORE-05: Тегирование заметок {#SR-VOC-CORE-05}
### 1. Цель и ключевые принципы
- **Многомерная фильтрация:** Заметки могут иметь несколько тегов.
- **Умные сессии:** Возможность фильтровать карточки по тегам для прохождения внеочередных тренировок.
