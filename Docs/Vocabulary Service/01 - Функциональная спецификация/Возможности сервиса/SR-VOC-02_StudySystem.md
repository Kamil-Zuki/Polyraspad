# SR-VOC-02: Система Интервального Повторения (FSRS)

## Описание
Данный блок отвечает за расчет расписания повторений карточек с использованием алгоритма FSRS (Free Spaced Repetition Scheduler). Сервис Vocabulary хранит состояние памяти пользователя для каждой карточки и общается с Python-микросервисом (`inclusive`), который выполняет математические расчеты FSRS.

## Основные возможности

### 1. Формирование очереди (Study Queue)
- При запуске Study Session система формирует очередь из:
  - `New` (новые карточки).
  - `Learning` / `Relearning` (карточки, находящиеся в процессе изучения в тот же день).
  - `Review` (карточки, для которых наступил срок повторения, `Due <= DateTime.UtcNow`).
- Очередь перемешивается и лимитируется дневными лимитами (`NewCardsLimit`, `ReviewsLimit`).

### 2. Оценка ответа (Review Rating)
- Пользователь отвечает на карточку, выбирая оценку (1 = Again, 2 = Hard, 3 = Good, 4 = Easy).
- `VocabularyService` отправляет текущий `FsrsState` и оценку в микросервис `inclusive`.
- Микросервис возвращает обновленный стейт (следующая дата `Due`, `Stability`, `Difficulty`).
- VocabularyService сохраняет обновленный `FsrsState` в базу данных.

### 3. Leeches (Проблемные карточки)
- Карточки, которые пользователь забывает слишком часто (`Lapses >= Threshold`), помечаются как проблемные (Leeches).
- Пользователь может запросить помощь у ИИ-агента для проработки таких карточек.

## Интеграции
- **inclusive (Python Microservice)**: gRPC `ReviewCard` метод, принимающий текущий статус и рейтинг, и возвращающий новый статус.
- **Agent Service**: может читать статистику по Leech-карточкам через tool `get_recent_leeches`.
