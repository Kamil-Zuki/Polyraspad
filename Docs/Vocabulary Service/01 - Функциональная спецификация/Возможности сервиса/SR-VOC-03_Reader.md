# SR-VOC-03: Ридер и прогресс чтения (Reader Progress)

## Описание
Блок описывает требования Vocabulary Service к прогрессу чтения и связке с внешней библиотекой книг. **Сами книги/главы/частотные индексы документов в Vocabulary EF не хранятся** — библиотека живёт в MediaService; термины и статусы — в группе Linguistics (`SR-VOC-05`).

---

## Возможности данного раздела

| Код | Название и Описание |
| :--- | :--- |
| **SR-VOC-READ-01** | **Прогресс чтения книги:** сохранение позиции и процента в `UserBookProgress` по внешнему `BookId`. |
| **SR-VOC-READ-02** | **Интеграция с Media Library:** файлы и метаданные книг — MediaService; Vocabulary хранит только прогресс и термины. |
| **SR-VOC-READ-03** | **Анализ текста для ридера:** через `AnalyzeText` (см. `SR-VOC-LING-06`) — без локальных Document entities. |

---

# Детальная спецификация требований

## SR-VOC-READ-01: Прогресс чтения книги {#SR-VOC-READ-01}
### 1. Цель и ключевые принципы

| Принцип | Описание |
| :--- | :--- |
| External BookId | Книга идентифицируется строковым `BookId` (MediaService). |
| Resume | Хранятся `ProgressPercent`, `LastPositionLocator`, `LastChapter`, `IsFinished`. |

### 2. Высокоуровневое описание
При чтении клиент обновляет `UserBookProgress` в рамках `ProjectId` пользователя.

### 3. Примеры взаимодействия (логические сценарии)

#### Сценарий А: Сохранение позиции
1. Пользователь перелистывает страницу PDF.
2. Клиент сохраняет `LastPositionLocator` и `ProgressPercent`.
3. При повторном открытии позиция восстанавливается.

---

## SR-VOC-READ-02: Интеграция с Media Library {#SR-VOC-READ-02}
### 1. Цель и ключевые принципы

| Принцип | Описание |
| :--- | :--- |
| Separation of concerns | Upload/list/share книг — MediaService; статусы слов — Vocabulary. |

### 2. Высокоуровневое описание
Vocabulary не создаёт `Document`/`DocumentChapter`. Импорт файла книги идёт в Media; прогресс — в Vocabulary.

### 3. Примеры взаимодействия (логические сценарии)

#### Сценарий А: Открытие книги из библиотеки
1. Клиент получает book id из MediaService.
2. Vocabulary отдаёт/создаёт `UserBookProgress` для пары (user, project, bookId).

---

## SR-VOC-READ-03: Анализ текста для ридера {#SR-VOC-READ-03}
### 1. Цель и ключевые принципы

| Принцип | Описание |
| :--- | :--- |
| Нет DocumentTermCount | Частотный индекс документа в Vocabulary EF отсутствует. |
| Live analyze | Подсветка строится через AnalyzeText + UserTermStatus. |

### 2. Высокоуровневое описание
Сложность/подсветка на странице опирается на статусы терминов пользователя, а не на persisted `DocumentTermCount`.

### 3. Примеры взаимодействия (логические сценарии)

#### Сценарий А: Рендер страницы
1. Клиент отправляет текст страницы в AnalyzeText.
2. Получает токены со статусами и рисует подсветку.
