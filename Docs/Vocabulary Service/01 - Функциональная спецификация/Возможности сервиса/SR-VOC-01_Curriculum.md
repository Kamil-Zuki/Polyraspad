# SR-VOC-01: Управление Учебным Планом (Curriculum)

## Описание
Данный функциональный блок отвечает за ведение пошаговой программы обучения пользователя, состоящей из уроков, разбитых по уровням CEFR (от A1 до C2). Система отслеживает успешность прохождения уроков, время, затраченное на обучение, и управляет доступностью новых уроков.

## Основные возможности

### 1. Прохождение уроков
- Пользователь может начать урок, инициируя чат-сессию в `AgentService`.
- Система фиксирует статус `InProgress` и сохраняет идентификатор потока (`AgentThreadId`).
- По завершении урока (решает ИИ), ИИ вызывает специальный tool, и VocabularyService переводит урок в статус `Completed`, сохраняя итоговый балл `ScorePercent` и время сессии `TimeSpentSeconds`.

### 2. Подсчет прогресса уровня CEFR
- Уроки сгруппированы по уровням CEFR.
- При изменении статуса любого урока система пересчитывает прогресс уровня (сущность `UserCefrProgress`).
- Если все уроки уровня A1 пройдены, уровень A1 помечается как `Completed`.

### 3. Блокировка и порядок (Linear Progression)
- Уроки могут иметь строгую связь через поле `UnlocksAfterLessonId` — урок недоступен, пока не пройден предыдущий.
- На уровне UI действует линейная блокировка: уровни проходятся последовательно. Например, нельзя начать уроки B1, пока не закрыт уровень A2 (если не пройден Placement Test).

### 4. Входное диагностическое тестирование (Placement Test)
- При первой регистрации (или по желанию пользователя через кнопку Retake Placement Test на Curriculum Map) пользователь может запустить Placement Test.
- Специальный диагностический ИИ-агент общается с пользователем и определяет его стартовый уровень (например, B1).
- Агент вызывает метод `SetPlacementLevel`, который автоматически помечает все уроки из младших уровней (A1 и A2) как `Completed` (с баллом 100%), открывая пользователю доступ сразу к урокам целевого уровня.
- Если тестирование проходится повторно и система определяет более низкий уровень (например, пользователь понижается с B2 на A2), метод `SetPlacementLevel` также корректно сбрасывает (удаляет) прогресс для уроков старших уровней (начиная с нового установленного уровня и выше), возвращая их в невыполненное состояние.

## Интеграции
- **Agent Service**: используется для проведения уроков и диагностики.
- **Aggregator Service**: проксирует запросы на UI, добавляя контекст (например, `SystemPromptOverride` для Placement Test).
- **Frontend (UI)**: рисует карту Curriculum Map и блокирует недоступные уроки.
