# Введение

Настоящий документ содержит описание регламента работы с Redis микросервиса **Authorization Service**. В архитектуре безопасности Платформы Redis играет критическую роль In-Memory Data Grid, обеспечивая сверхбыстрый доступ к данным сессий, защиту от брутфорса (Rate Limiting), JIT-кэширование контекста, реализацию паттернов "Phantom Token" и "Zero Trust" (КАР-1, КАР-2), а также синхронизацию состояния между узлами кластера.

Цель документа — определить правила именования ключей (Key Naming Conventions), политики TTL (Time-To-Live) и механизмы инвалидации кэша, которые инженеры должны применять при разработке. Документ базируется на функциональных требованиях (SR-AUTH-xxx) и КАР.
