# Обзор высокого уровня

**Authorization Module** — domain-сервис identity Polyraspad. Хранит пользователей в PostgreSQL, выдаёт JWT, принимает gRPC от Aggregator Service. Stateless access tokens; refresh state в БД.

Ключевые паттерны: ASP.NET Core Identity, symmetric JWT, refresh rotation, gRPC-first API, fail-fast production config.

| Метрика | Значение |
| :--- | :--- |
| Runtime | .NET 10 |
| gRPC port | `5027` (h2c) |
| Database | PostgreSQL `auth-module` |
| Primary consumer | Aggregator Service |

## Интеграции

```
Browser → Aggregator (REST + JWT validate) ──gRPC h2c──► Authorization Module
                                                              │
                                                              ├── PostgreSQL (auth-module)
                                                              └── SMTP (confirm email)
```

REST clients (dev) могут обращаться напрямую к `/api/v1/auth` с JWT Bearer на protected routes.
