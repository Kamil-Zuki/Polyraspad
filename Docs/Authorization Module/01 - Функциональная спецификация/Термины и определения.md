# Термины и определения

| Термин | Определение |
| :--- | :--- |
| **Authorization Module** | Микросервис identity Polyraspad (`authorization-module/`), порт gRPC `5027`, БД PostgreSQL `auth-module`. |
| **Access token (JWT)** | Короткоживущий подписанный токен (HMAC-SHA256). Claim `sub` = userId. Валидируется Aggregator локально по общему `Jwt:Secret`. |
| **Refresh token** | Opaque Base64 строка в таблице `RefreshTokens`; TTL 7 дней; rotation при refresh. |
| **Aggregator Service** | BFF / API Gateway; единственный публичный REST для браузера; вызывает auth по gRPC. |
| **Identity / ApplicationUser** | ASP.NET Core Identity user entity; email + password hash. |
| **Email confirmation** | Обязательный шаг перед login; one-time token из Identity + SMTP link. |
| **gRPC metadata `user_id`** | Заголовок, который Aggregator передаёт на protected RPC после локальной JWT validation. |
