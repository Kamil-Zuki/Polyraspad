# Нефункциональные требования

## Безопасность

| ID | Требование |
| :--- | :--- |
| NFR-AUTHMOD-SEC-01 | `Jwt:Secret` ≥ 32 символов; одинаковый secret у Aggregator и auth-module. |
| NFR-AUTHMOD-SEC-02 | Пароль: min 6 символов, ≥ 1 uppercase, ≥ 1 special char; confirm must match. |
| NFR-AUTHMOD-SEC-03 | Login только при `EmailConfirmed = true`. |
| NFR-AUTHMOD-SEC-04 | Protected gRPC: userId из metadata; mismatch request.user_id vs metadata → PermissionDenied. |
| NFR-AUTHMOD-SEC-05 | Production: placeholder config values → fail-fast at startup. |

## Производительность и доступность

| ID | Требование |
| :--- | :--- |
| NFR-AUTHMOD-PERF-01 | gRPC h2c на `:5027`; max message size 1 GB (config). |
| NFR-AUTHMOD-PERF-02 | `/healthz` без deep dependency checks. |
