# LingQ-Style UX Acceptance Criteria

**Цель:** Четкие критерии приемки для LingQ-style experience в Reader и Library.

## Reader - Основные сценарии

### AC-1: Открытие и визуальная подсветка

**Критерии:**
- [ ] При открытии текста все слова имеют визуальный статус (цвет)
- [ ] Цветовая схема соответствует статусам:
  - NEW: `text-blue-400`
  - LINGQ: `text-yellow-400`
  - KNOWN: `text-white`
  - IGNORED: `text-white/40`
- [ ] Фразы отображаются с приоритетом над отдельными словами
- [ ] При наведении на слово появляется cursor-pointer
- [ ] Нет мигания или задержки при первой загрузке (> 500ms считается проблемой)

### AC-2: Term Inspector

**Критерии:**
- [ ] Клик по слову открывает инспектор за < 300ms
- [ ] Инспектор показывает предложение с выделенным словом
- [ ] Автоматический перевод загружается за < 2s (с индикатором загрузки)
- [ ] Поле для своего значения доступно сразу
- [ ] Кнопки действий видны без скролла
- [ ] Escape или клик вне закрывает инспектор

### AC-3: Создание LingQ

**Критерии:**
- [ ] Нажатие "Create LingQ" сохраняет термин за < 1s
- [ ] Слово меняет цвет на желтый сразу после сохранения
- [ ] Повторный клик на это слово показывает сохраненное значение
- [ ] Термин появляется в списке дубликатов для других форм

### AC-4: Known и Ignore

**Критерии:**
- [ ] Нажатие "Known" меняет цвет на белый немедленно
- [ ] "Known" слова не подсвечиваются как NEW в других текстах
- [ ] "Ignore" делает слово приглушенным и не кликабельным
- [ ] IGNORED слова не учитываются в статистике текста

### AC-5: Phrase Selection

**Критерии:**
- [ ] Shift+клик позволяет выбрать диапазон слов
- [ ] Максимум 8 слов (настройка) - превышение блокирует выбор
- [ ] Выделенная фраза подсвечивается отдельным цветом
- [ ] Инспектор для фразы показывает полный текст фразы
- [ ] Сохраненная фраза подсвечивается поверх отдельных слов

### AC-6: Page Turn → Bulk Known

**Критерии:**
- [ ] Настройка "Mark blue as known" сохраняется
- [ ] При включенной настройке: перелистывание помечает все NEW как KNOWN
- [ ] Операция выполняется за < 500ms (bulk endpoint)
- [ ] При выключенной настройке: NEW остаются NEW
- [ ] Прогресс-бар показывает обновление статусов

### AC-7: Review из Reader

**Критерии:**
- [ ] Счетчик "Review: N" виден всегда когда N > 0
- [ ] Нажатие "Review" запускает SRS-сессию за < 2s
- [ ] Карточки в сессии - due items из текущего контекста
- [ ] После review возврат в reader на ту же позицию
- [ ] Прогресс review сохраняется при прерывании

### AC-8: Resume Reading

**Критерии:**
- [ ] Открытие книги возобновляет с последней страницы
- [ ] Для текста - с последнего offset
- [ ] "Continue Reading" на dashboard ведет к последнему контенту
- [ ] Если > 24h с последнего чтения - показывать reminder

## Library - Content-First

### AC-9: Continue Reading Section

**Критерии:**
- [ ] Виден если есть незавершенный контент
- [ ] Показывает обложку, название, прогресс
- [ ] Кнопка "Continue" ведет к позиции
- [ ] Сортирует по lastOpenedAt desc

### AC-10: Book Cards

**Критерии:**
- [ ] Обложка или placeholder
- [ ] Название (обрезается если > 2 строк)
- [ ] Progress bar реальный (не placeholder)
- [ ] Stats: known/learning/new counts
- [ ] Hover эффект с quick actions

### AC-11: Import Content

**Критерии:**
- [ ] Кнопка импорта видна на всех страницах Library
- [ ] PDF upload с progress indicator
- [ ] После upload - автоматический переход в reader
- [ ] Обработка ошибок с human-readable messages

## Performance Standards

| Операция | Target | Max Acceptable |
|----------|--------|----------------|
| Text analyze | < 1s | 3s |
| Term inspector open | < 300ms | 1s |
| Create LingQ | < 500ms | 2s |
| Page turn | < 200ms | 500ms |
| Bulk known | < 500ms | 2s |
| Review start | < 2s | 5s |
| Library load | < 1s | 3s |

## Accessibility

- [ ] Все интерактивные элементы доступны с клавиатуры
- [ ] Tab order логичен (left→right, top→bottom)
- [ ] Aria labels для кнопок действий
- [ ] Контраст цветов WCAG 2.1 AA
- [ ] Screen reader announce для статус changes

## Regression Tests

Обязательные проверки перед релизом:

### Form Distinction
- [ ] `sleep` и `slept` имеют разные статусы
- [ ] `go` и `went` не дублируют друг друга

### Phrase Priority
- [ ] "take off" как фраза отображается едино
- [ ] Отдельные "take" и "off" не ломают фразу

### Exact Duplicates
- [ ] Точный дубликат находится поиском
- [ ] Компонентные слова фразы не считаются дублями

### Page Turn Setting
- [ ] При включенной настройке: синие становятся known
- [ ] При выключенной: синие остаются синими

## Definition of Done

Фича считается завершенной когда:
1. ✅ Все AC для фичи выполнены
2. ✅ Performance criteria met
3. ✅ Accessibility проверена
4. ✅ Regression tests проходят
5. ✅ Code review пройден
6. ✅ Documentation обновлена
