# Термины и определения

| Термин | Определение |
| :--- | :--- |
| **Thread (тред)** | Контейнер диалога пользователя в одном `project_id`; хранит messages, runs, artifacts. |
| **Run (запуск)** | Один обмен user→assistant с audit: domain decision, tool calls, optional model id. |
| **ExecuteRun** | Server-side orchestration: classify → route → execute tool → persist через CreateRun. |
| **CreateRun** | Persist готового run payload (используется ExecuteRun и потенциально client-driven flows). |
| **Domain decision** | Классификация запроса: allowed + category + reason; 1:1 с run. |
| **Intent / tool** | Маршрутизированное действие (`explain_word`, `navigate`, …). |
| **Artifact** | JSON payload, привязанный к run (draft карточки, navigation hints). |
| **PolyGuide** | Product name AI-ассистента в UI; term-first, language-learning only. |
| **Term-first** | Обучение по exact surface forms; без lemma labels в ответах агента. |
| **Project scope** | Все thread operations требуют валидного доступа к project через VocabularyService. |
| **gRPC metadata** | `user_id`, `roles` — из Aggregator/JWT context через GrpcContextHelper. |
