## Введение

Настоящий документ определяет функциональные возможности (сервисные требования) микросервиса **«Agent Service»** — AI-ассистента платформы Polyraspad (PolyGuide).

**Agent Service** хранит треды диалога пользователя в контексте языкового проекта, историю сообщений и аудит запусков (runs). Основной сценарий — **ExecuteRun**: классификация домена, маршрутизация намерения, вызов learning tools (LLM или VocabularyService) и атомарное сохранение результата. Публичный REST — через Aggregator; сервис принимает только **gRPC**.

Документ предназначен для разработчиков, QA, системных аналитиков и архитекторов.

# Группы возможностей

Ниже представлен перечень из 11 групп функциональных возможностей (сервисных требований) для микросервиса Agent Service. Требования сгруппированы по логическим блокам для удобства навигации.

| Группа | Название и Описание |
| :----- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Управление тредами (Thread Management)** | **Thread lifecycle:** Список, создание, получение и архивация AI-тредов в project scope. |
| **История сообщений (Message History)** | **Message log:** Cursor-пагинация истории user/assistant сообщений треда. |
| **Запуски агента (Agent Runs)** | **Run persistence:** CreateRun (client payload) и ExecuteRun (server orchestration). |
| **Доменная политика (Domain Policy)** | **Domain gate:** Классификация in/out of scope до LLM-tools; refusal copy. |
| **Маршрутизация намерений (Intent Routing)** | **Intent router:** Regex-based выбор tool по user text. |
| **Инструменты обучения (Learning Tools)** | **Learning tools:** explain_word, grammar_help, generate_example, build_card_draft, general_answer. |
| **Навигация и прогресс (Navigation & Progress)** | **Product tools:** navigate (Reader/Study/…) и get_progress (stats). |
| **Артефакты (Artifacts)** | **Run artifacts:** Create и list structured JSON payloads. |
| **Интеграция с Vocabulary (Vocabulary Integration)** | **Vocabulary gRPC:** Project access, analytics, AI mining helpers. |
| **LLM-провайдер (LLM Provider)** | **OpenAI-compatible LLM:** Chat completion для explain/general paths. |
| **Платформенные контракты (Operations)** | **Platform ops:** healthz, EF migrations, gRPC-only Kestrel. |

## Описание возможностей

Ниже представлен детальный перечень сервисных требований (SR) для каждой группы. Подробное описание каждого требования находится в соответствующих вложенных документах.

### 1. Управление тредами (Thread Management)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-THREAD-01** | **Список тредов проекта:** Активные (не archived) треды user+project, сортировка по `updated_at` DESC. |
| **SR-AGENT-THREAD-02** | **Создание треда:** Новый пустой тред после проверки доступа к project. |
| **SR-AGENT-THREAD-03** | **Получение треда:** Детали треда по id с проверкой ownership. |
| **SR-AGENT-THREAD-04** | **Архивация треда:** Soft archive (`archived_at`); идempotent повтор. |

### 2. История сообщений (Message History)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-MSG-01** | **List messages с cursor:** До 100 сообщений; `before` message id для older page. |

### 3. Запуски агента (Agent Runs)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-RUN-01** | **CreateRun (persist):** Атомарное сохранение user+assistant messages, run, domain decision, tool calls. |
| **SR-AGENT-RUN-02** | **ExecuteRun (orchestrate):** Domain classify → intent route → tool execute → CreateRun persist. |

### 4. Доменная политика (Domain Policy)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-DOM-01** | **Domain classification:** Regex-категории language_learning / product_navigation / progress / out_of_scope. |
| **SR-AGENT-DOM-02** | **Out-of-scope refusal:** Шаблон отказа с suggested prompts; блок LLM tools при disallowed. |

### 5. Маршрутизация намерений (Intent Routing)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-INTENT-01** | **Intent routing:** Приоритет navigation → progress → grammar → example → card → explain → general/out_of_scope. |

### 6. Инструменты обучения (Learning Tools)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-TOOL-01** | **explain_word:** LLM-объяснение exact surface form; editor draft action. |
| **SR-AGENT-TOOL-02** | **grammar_help:** Vocabulary AIService ExplainGrammar. |
| **SR-AGENT-TOOL-03** | **generate_example:** Vocabulary GenerateContext + card draft action. |
| **SR-AGENT-TOOL-04** | **build_card_draft:** Card draft с optional example generation. |
| **SR-AGENT-TOOL-05** | **general_answer:** PolyGuide system prompt; term-first, no code. |
| **SR-AGENT-TOOL-06** | **custom_roleplay:** Запуск интерактивной ролевой игры или диалога с ИИ-тьютором на основе выбранного кастомного/системного сценария. |

### 7. Навигация и прогресс (Navigation & Progress)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-NAV-01** | **navigate tool:** Action cards для Reader, Editor, Study, Vocabulary, Import, Library. |
| **SR-AGENT-NAV-02** | **get_progress tool:** Daily summary + vocabulary stats из AnalyticsService. |

### 8. Артефакты (Artifacts)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-ART-01** | **Create artifact:** JSON payload привязан к run+thread; ownership check. |
| **SR-AGENT-ART-02** | **List artifacts:** По thread, optional filter по run_id. |

### 9. Интеграция с Vocabulary (Vocabulary Integration)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-VOC-01** | **Project access validation:** ContentService GetProjectDetails + metadata roles. |
| **SR-AGENT-VOC-02** | **Analytics и AI helpers:** GetVocabularyStats, GetDailySummary, ExplainGrammar, GenerateContext. |

### 10. LLM-провайдер (LLM Provider)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-LLM-01** | **OpenAI-compatible completion:** HttpClient к `Ai:BaseUrl`; model/timeout из options. |

### 11. Платформенные контракты (Operations)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-OPS-01** | **Health check:** GET `/healthz` → `{ status: ok }`. |
| **SR-AGENT-OPS-02** | **Startup migrations:** EF Core Migrate при старте приложения. |
| **SR-AGENT-OPS-03** | **gRPC-only Kestrel:** HTTP/2 на порту 5131; без REST controllers. |

Подробные SR-блоки — во вложенных файлах групп. gRPC-контракты — в `04 - Бекенд, API и Контракты/`.
