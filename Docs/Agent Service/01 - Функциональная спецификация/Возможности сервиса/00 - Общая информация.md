## Введение

Настоящий документ определяет функциональные возможности (сервисные требования) микросервиса **«Agent Service»** — AI-ассистента платформы Polyraspad (PolyGuide).

**Agent Service** хранит треды диалога пользователя в контексте языкового проекта, историю сообщений и аудит запусков (runs). Основной сценарий — **ExecuteRun**: LLM chat completion с function-calling tools (Vocabulary gRPC), опциональная подсказка intent (`GeneratePractice` / initial greeting daily plan), атомарное сохранение результата через CreateRun. Публичный REST — через Aggregator; сервис принимает только **gRPC**.

Документ предназначен для разработчиков, QA, системных аналитиков и архитекторов.

# Группы возможностей

Ниже представлен перечень из 11 групп функциональных возможностей (сервисных требований) для микросервиса Agent Service. Требования сгруппированы по логическим блокам для удобства навигации.

| Группа | Название и Описание |
| :----- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Управление тредами (Thread Management)** | **Thread lifecycle:** Список (опциональный `agent_id`), создание (`agent_id` / `system_prompt_override`), получение и архивация AI-тредов в project scope. |
| **История сообщений (Message History)** | **Message log:** Cursor-пагинация истории user/assistant сообщений треда. |
| **Запуски агента (Agent Runs)** | **Run persistence:** CreateRun (client payload) и ExecuteRun (LLM tool loop + persist). |
| **Доменная политика (Domain Policy)** | **Domain gate:** Классификация и validator categories; CreateRun audit; ExecuteRun v1 пишет `language_learning`. |
| **Маршрутизация намерений (Intent Routing)** | **Intent router:** Regex hints (`GeneratePractice`, `GetDailyPlan`, navigate destinations); не выбирает classic tool handlers в ExecuteRun. |
| **Инструменты обучения (Learning Tools)** | **Learning tools:** LLM function tools (deck/card/stats/lessons/placement/plan) + reserved CustomScenario; classic intent IDs — не primary ExecuteRun path. |
| **Навигация и прогресс (Navigation & Progress)** | **Product surfaces:** navigate destinations (Reader/Study/Shadowing/Decks/…) via ACTION lines; progress via Vocabulary stats tool. |
| **Артефакты (Artifacts)** | **Run artifacts:** Create и list structured JSON payloads. |
| **Интеграция с Vocabulary (Vocabulary Integration)** | **Vocabulary gRPC:** Project access, analytics, AI helpers, lessons, placement, daily plan. |
| **LLM-провайдер (LLM Provider)** | **OpenAI-compatible LLM:** Chat completion + tool definitions для ExecuteRun loop. |
| **Платформенные контракты (Operations)** | **Platform ops:** healthz, EF migrations, gRPC-only Kestrel. |

## Описание возможностей

Ниже представлен детальный перечень сервисных требований (SR) для каждой группы. Подробное описание каждого требования находится в соответствующих вложенных документах.

### 1. Управление тредами (Thread Management)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-THREAD-01** | **Список тредов проекта:** Активные (не archived) треды user+project, сортировка по `updated_at` DESC. |
| **SR-AGENT-THREAD-02** | **Создание треда:** Новый пустой тред; optional `agent_id`, `system_prompt_override`. |
| **SR-AGENT-THREAD-03** | **Получение треда:** Детали треда по id с проверкой ownership. |
| **SR-AGENT-THREAD-04** | **Архивация треда:** Soft archive (`archived_at`); идемpotent повтор. |
| **SR-AGENT-THREAD-05** | **Фильтр по agent_id:** `ListThreads` optional `agent_id` — только треды с совпадающим `agent_id`. |

### 2. История сообщений (Message History)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-MSG-01** | **List messages с cursor:** До 100 сообщений; `before` message id для older page. |

### 3. Запуски агента (Agent Runs)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-RUN-01** | **CreateRun (persist):** Атомарное сохранение user+assistant messages, run, domain decision, tool calls. |
| **SR-AGENT-RUN-02** | **ExecuteRun (LLM tool loop):** History + system prompt → LLM CompleteChat (tools) → ExecuteToolCore → CreateRun persist. |

### 4. Доменная политика (Domain Policy)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-DOM-01** | **Domain classification:** Regex-категории; CreateRun validator: language_learning / product_navigation / progress / out_of_scope / automation. |
| **SR-AGENT-DOM-02** | **Out-of-scope refusal:** Шаблон отказа с suggested prompts (`AgentDomainPolicy`); не блокирует текущий ExecuteRun LLM loop (см. ISSUE-003). |

### 5. Маршрутизация намерений (Intent Routing)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-INTENT-01** | **Intent routing hints:** Priority includes navigate (Shadowing/Decks), progress, grammar, practice, card, explain, get_daily_plan, general/out_of_scope; ExecuteRun uses GeneratePractice (+ initial greeting plan) only. |

### 6. Инструменты обучения (Learning Tools)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-TOOL-01** | **explain_word (intent id):** Regex intent; не server-side handler в текущем ExecuteRun — ответ через LLM chat. |
| **SR-AGENT-TOOL-02** | **grammar_help (intent id):** Regex intent; не ExecuteToolCore handler. |
| **SR-AGENT-TOOL-03** | **generate_example (intent id):** Regex intent; не ExecuteToolCore handler. |
| **SR-AGENT-TOOL-04** | **build_card_draft (intent id):** Regex intent; создание карточки — LLM tool `create_card`. |
| **SR-AGENT-TOOL-05** | **general_answer (intent id):** Fallback domain classify; ExecuteRun всегда идёт в LLM chat. |
| **SR-AGENT-TOOL-06** | **custom_roleplay (reserved):** Entity `CustomScenario` в БД; CRUD/gRPC/ExecuteRun wiring отсутствует. |
| **SR-AGENT-TOOL-07** | **create_deck:** LLM tool → Vocabulary CreateDeck. |
| **SR-AGENT-TOOL-08** | **create_card:** LLM tool → Vocabulary CreateCard (deck_id или first deck). |
| **SR-AGENT-TOOL-09** | **get_user_vocabulary_stats:** LLM tool → GetVocabularyStats. |
| **SR-AGENT-TOOL-10** | **get_recent_leeches:** LLM tool → GetLeechCards. |
| **SR-AGENT-TOOL-11** | **mark_lesson_completed:** LLM tool → CompleteLesson. |
| **SR-AGENT-TOOL-12** | **submit_knowledge_check:** LLM tool → SubmitKnowledgeCheckResult. |
| **SR-AGENT-TOOL-13** | **set_cefr_placement:** LLM tool → SetPlacementLevel; loop break after success. |
| **SR-AGENT-TOOL-14** | **get_daily_plan:** LLM tool → GetDailyPlan; также inject при `IsInitialGreeting`. |
| **SR-AGENT-TOOL-15** | **generate_writing_task:** LLM tool → GetLearningTerms + instruction payload. |
| **SR-AGENT-TOOL-16** | **get_skill_assessment_history:** LLM tool → GetSkillAssessmentHistory. |

### 7. Навигация и прогресс (Navigation & Progress)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-NAV-01** | **navigate destinations:** Reader, Editor, Study, Vocabulary, Import, Library, Shadowing, Decks (intent + ACTION:NAVIGATE lines). |
| **SR-AGENT-NAV-02** | **get_progress / stats:** Vocabulary stats via LLM tool `get_user_vocabulary_stats` (и related analytics). |

### 8. Артефакты (Artifacts)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-ART-01** | **Create artifact:** JSON payload привязан к run+thread; ownership check. |
| **SR-AGENT-ART-02** | **List artifacts:** По thread, optional filter по run_id. |

### 9. Интеграция с Vocabulary (Vocabulary Integration)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-VOC-01** | **Project access validation:** ContentService GetProjectDetails + metadata roles. |
| **SR-AGENT-VOC-02** | **Analytics и AI helpers:** GetVocabularyStats, GetDailySummary, ExplainGrammar, GenerateContext, leeches, learning terms. |
| **SR-AGENT-VOC-03** | **Учебный план и оценка уровня:** Lessons Complete, SubmitKnowledgeCheck, SetPlacementLevel, GetDailyPlan, skill assessment history. |

### 10. LLM-провайдер (LLM Provider)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-LLM-01** | **OpenAI-compatible completion:** HttpClient к `Ai:BaseUrl`; `CompleteChatAsync` с tool definitions. |

### 11. Платформенные контракты (Operations)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-AGENT-OPS-01** | **Health check:** GET `/healthz` → `{ status: ok }`. |
| **SR-AGENT-OPS-02** | **Startup migrations:** EF Core Migrate при старте приложения. |
| **SR-AGENT-OPS-03** | **gRPC-only Kestrel:** HTTP/2 на порту 5131; без REST controllers. |

Подробные SR-блоки — во вложенных файлах групп. gRPC-контракты — в `04 - Бекенд, API и Контракты/`.
