# Инструменты Агента (Agent Tools)

AgentService предоставляет ИИ-модели (LLM) набор инструментов (Tools) для взаимодействия с платформой. Эти инструменты реализованы в классе `AgentOrchestrator` и делегируют выполнение соответствующим gRPC-клиентам (например, `VocabularyGrpcClient`).

## 1. get_user_vocabulary_stats
Получает базовую статистику словаря пользователя (количество карточек по статусам New, Learning, Review). Помогает агенту понять общую картину и дать советы по расписанию.

## 2. create_deck
Создает новую колоду в выбранном проекте. 
**Параметры:** `title`, `description`, `parent_deck_id`.

## 3. get_recent_leeches
Возвращает список "проблемных" карточек (leeches), на которых пользователь часто ошибался. Используется для персонализированных микро-сессий повторения (например, агент просит перевести эти сложные слова).

## 4. set_cefr_placement
**Назначение:** Используется специализированным агентом (Placement Copilot) по завершении диагностического теста.
**Действие:** Вызывает метод `SetPlacementLevel` в `VocabularyService`, который проставляет статус `Completed` с `ScorePercent = 100` всем урокам, уровень которых ниже указанного.
**Параметры:** 
- `cefr_level` (string) — выявленный уровень, например "A1", "A2", "B1", "B2", "C1", "C2".

> [!WARNING]  
> Данный инструмент должен вызываться **только** после уверенной оценки знаний пользователя. Для этого `AggregatorService` позволяет передать `SystemPromptOverride` при создании потока, жестко инструктируя агента не вызывать этот tool до завершения диагностики.

## Механизм SystemPromptOverride
При создании нового потока (`CreateThread`) клиент может передать `SystemPromptOverride`.
Если этот параметр задан:
1. `AgentService` игнорирует стандартный промпт (Study Copilot).
2. Используется переданный промпт (например, промпт строгого экзаменатора для Placement Test).
3. Инструменты (такие как `set_cefr_placement`) остаются доступными оркестратору, но ИИ вызывает их согласно новой инструкции.
