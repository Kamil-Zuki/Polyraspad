# Введение

Данный документ описывает protobuf-сообщения (DTO) группы **Треды и сообщения**, используемые RPC `ListThreads`, `CreateThread`, `GetThread`, `ListMessages`, `ArchiveThread`. Поля согласованы с сущностями `agent_threads` и `agent_messages`.

**SR:** SR-AGENT-THREAD-01 … SR-AGENT-THREAD-04, SR-AGENT-MSG-01. gRPC: [[../gRPC/01 - Треды и сообщения (Threads)]].

# 1. Список DTO

| **Название DTO** | **Назначение** |
| :--- | :--- |
| **ListAgentThreadsRequest** | Запрос: project_id для списка тредов. |
| **ListAgentThreadsResponse** | Ответ: массив `AgentThreadListItem`. |
| **AgentThreadListItem** | Элемент списка тредов (без archived_at). |
| **CreateAgentThreadRequest** | Запрос: project_id для создания треда. |
| **GetAgentThreadRequest** | Запрос: thread_id. |
| **AgentThreadResponse** | Ответ: полный тред incl. archived_at. |
| **ListAgentMessagesRequest** | Запрос: thread_id, limit, cursor before. |
| **ListAgentMessagesResponse** | Ответ: messages + next_before cursor. |
| **AgentMessageItem** | Сообщение в истории (read model). |
| **ArchiveAgentThreadRequest** | Запрос: thread_id для archive. |

# DTO: AgentThreadListItem

## Контекст и назначение

Элемент списка активных тредов в UI PolyGuide (sidebar). Не содержит `archived_at` — archived треды не попадают в list.

**Назначение:** Ответ (элемент коллекции).
**Реализация сущности:** Таблица `agent_threads`.

## Структура данных

| **Имя поля (JSON)** | **Тип данных** | **Описание** |
| :--- | :--- | :--- |
| `id` | `uuid` | Идентификатор треда. |
| `project_id` | `uuid` | Языковой проект Polyraspad. |
| `title` | `string` | Заголовок (derived или default «New conversation»). |
| `created_at` | `datetime` | UTC создания. |
| `updated_at` | `datetime` | UTC последней активности. |

## Пример работы (JSON)

```json
{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "project_id": "42424242-4242-4242-4242-424242424242",
  "title": "Explain the word slept",
  "created_at": "2026-06-28T10:00:00Z",
  "updated_at": "2026-06-28T10:05:00Z"
}
```

# DTO: AgentThreadResponse

## Контекст и назначение

Полная проекция треда для `GetThread`, `CreateThread`. Включает `archived_at` для определения soft-deleted state.

**Назначение:** Ответ (сущность).
**Реализация сущности:** Таблица `agent_threads`.

## Структура данных

| **Имя поля (JSON)** | **Тип данных** | **Описание** |
| :--- | :--- | :--- |
| `id` | `uuid` | Идентификатор треда. |
| `project_id` | `uuid` | Project scope. |
| `title` | `string` | Заголовок треда. |
| `created_at` | `datetime` | UTC создания. |
| `updated_at` | `datetime` | UTC обновления. |
| `archived_at` | `datetime \| null` | Soft archive timestamp; null = active. |

## Пример работы (JSON)

```json
{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "project_id": "42424242-4242-4242-4242-424242424242",
  "title": "Grammar: went vs go",
  "created_at": "2026-06-28T09:00:00Z",
  "updated_at": "2026-06-28T09:30:00Z",
  "archived_at": null
}
```

# DTO: AgentMessageItem

## Контекст и назначение

Сообщение user/assistant/system/tool в истории треда. `metadata_json` — JSON string с intent_category, actions, refusal flags для UI.

**Назначение:** Ответ (элемент коллекции).
**Реализация сущности:** Таблица `agent_messages`.

## Структура данных

| **Имя поля (JSON)** | **Тип данных** | **Описание** |
| :--- | :--- | :--- |
| `id` | `uuid` | Идентификатор сообщения. |
| `role` | `string` | `user` \| `assistant` \| `system` \| `tool`. |
| `content` | `string` | Текст сообщения (plain text, no markdown). |
| `metadata_json` | `string \| null` | JSON metadata для assistant messages. |
| `created_at` | `datetime` | UTC создания. |

## Пример работы (JSON)

```json
{
  "id": "msg-uuid-0001",
  "role": "assistant",
  "content": "Opening Reader. You can continue there or ask me something else here.",
  "metadata_json": "{\"intent_category\":\"product_navigation\",\"actions\":[{\"id\":\"nav-reader\",\"title\":\"Reader\",\"kind\":\"navigate\",\"href\":\"/reader\"}]}",
  "created_at": "2026-06-28T10:05:01Z"
}
```

# DTO: ListAgentMessagesRequest

## Контекст и назначение

Запрос cursor-пагинации истории. `before` — id сообщения; возвращаются более старые записи.

**Назначение:** Запрос.
**Реализация сущности:** N/A (proto wrapper).

## Структура данных

| **Имя поля (JSON)** | **Тип данных** | **Описание** |
| :--- | :--- | :--- |
| `thread_id` | `uuid` | Тред. |
| `limit` | `int32` | 1..100; default 100 если <= 0. |
| `before` | `uuid \| null` | Cursor: id сообщения для older page. |

## Пример работы (JSON)

```json
{
  "thread_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "limit": 50,
  "before": "msg-uuid-0050"
}
```

# DTO: ListAgentMessagesResponse

## Контекст и назначение

Ответ `ListMessages`: хронологически упорядоченные items + optional cursor.

**Назначение:** Ответ.
**Реализация сущности:** N/A.

## Структура данных

| **Имя поля (JSON)** | **Тип данных** | **Описание** |
| :--- | :--- | :--- |
| `items` | `array<AgentMessageItem>` | Сообщения (old → new). |
| `next_before` | `uuid \| null` | Cursor для следующей страницы; null если конец. |

## Пример работы (JSON)

```json
{
  "items": [
    {
      "id": "msg-001",
      "role": "user",
      "content": "Open reader",
      "metadata_json": null,
      "created_at": "2026-06-28T10:05:00Z"
    }
  ],
  "next_before": null
}
```
