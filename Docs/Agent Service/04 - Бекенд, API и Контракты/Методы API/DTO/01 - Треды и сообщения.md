# Введение

Данный документ описывает protobuf-сообщения (DTO) группы **Треды и сообщения**, используемые RPC `ListThreads`, `CreateThread`, `GetThread`, `ListMessages`, `ArchiveThread`. Поля согласованы с сущностями `agent_threads` и `agent_messages`.

**SR:** SR-AGENT-THREAD-01 … SR-AGENT-THREAD-04, SR-AGENT-MSG-01. gRPC: [[../gRPC/01 - Треды и сообщения (Threads)]].

---

# 1. Список DTO

| **Название DTO** | **Назначение** |
| :--- | :--- |
| **ListAgentThreadsRequest** | Запрос: `user_id`, `project_id`, опциональный `agent_id` для фильтрации тредов. |
| **ListAgentThreadsResponse** | Ответ: массив `AgentThreadListItem`. |
| **AgentThreadListItem** | Элемент списка тредов (включая `agent_id`). |
| **CreateAgentThreadRequest** | Запрос: `user_id`, `project_id`, `agent_id`, опциональный `system_prompt_override`. |
| **GetAgentThreadRequest** | Запрос: `user_id`, `thread_id`. |
| **AgentThreadResponse** | Ответ: полный тред incl. `archived_at` и `agent_id`. |
| **ListAgentMessagesRequest** | Запрос: `user_id`, `thread_id`, `limit`, cursor `before`. |
| **ListAgentMessagesResponse** | Ответ: `items` + `next_before` cursor. |
| **AgentMessageItem** | Сообщение в истории (read model). |
| **ArchiveAgentThreadRequest** | Запрос: `user_id`, `thread_id` для архивации. |

# DTO: AgentThreadListItem

## Контекст и назначение

Элемент списка активных тредов в UI PolyGuide (sidebar). Не содержит `archived_at` — archived треды не попадают в list.

**Назначение:** Ответ (элемент коллекции).
**Реализация сущности:** Таблица `agent_threads`.

## Структура данных

| **Имя поля (JSON)** | **Тип данных** | **Описание** |
| :--- | :--- | :--- |
| `id` | `uuid` | Идентификатор треда. |
| `project_id` | `uuid` | Языковой проект Polyraspad. |
| `title` | `string` | Заголовок (derived или default «New conversation»). |
| `created_at` | `datetime` | UTC создания. |
| `updated_at` | `datetime` | UTC последней активности. |
| `agent_id` | `string \| null` | Идентификатор персонажа агента (например, `study-copilot`, `placement-copilot`). |

## Пример работы (JSON)

```json
{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "project_id": "42424242-4242-4242-4242-424242424242",
  "title": "Explain the word slept",
  "created_at": "2026-06-28T10:00:00Z",
  "updated_at": "2026-06-28T10:05:00Z",
  "agent_id": "study-copilot"
}
```

# DTO: AgentThreadResponse

## Контекст и назначение

Полная проекция треда для `GetThread`, `CreateThread`. Включает `archived_at` и `agent_id`.

**Назначение:** Ответ (сущность).
**Реализация сущности:** Таблица `agent_threads`.

## Структура данных

| **Имя поля (JSON)** | **Тип данных** | **Описание** |
| :--- | :--- | :--- |
| `id` | `uuid` | Идентификатор треда. |
| `project_id` | `uuid` | Project scope. |
| `title` | `string` | Заголовок треда. |
| `created_at` | `datetime` | UTC создания. |
| `updated_at` | `datetime` | UTC обновления. |
| `archived_at` | `datetime \| null` | Soft archive timestamp; null = active. |
| `agent_id` | `string \| null` | Идентификатор персонажа агента. |

## Пример работы (JSON)

```json
{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "project_id": "42424242-4242-4242-4242-424242424242",
  "title": "Grammar: went vs go",
  "created_at": "2026-06-28T09:00:00Z",
  "updated_at": "2026-06-28T09:30:00Z",
  "archived_at": null,
  "agent_id": "grammar-tutor"
}
```

# DTO: AgentMessageItem

## Контекст и назначение

Элемент истории сообщений в треде для `ListMessages`.

**Назначение:** Ответ (элемент коллекции).
**Реализация сущности:** Таблица `agent_messages`.

## Структура данных

| **Имя поля (JSON)** | **Тип данных** | **Описание** |
| :--- | :--- | :--- |
| `id` | `uuid` | Идентификатор сообщения. |
| `role` | `string` | Роль автора (`user`, `assistant`, `system`, `tool`). |
| `content` | `string` | Текст сообщения. |
| `metadata_json` | `string \| null` | Метаданные (JSON string). |
| `created_at` | `datetime` | UTC создания. |
