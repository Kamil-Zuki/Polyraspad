# Введение

Данный документ описывает protobuf-сообщения группы **Артефакты** для RPC `CreateArtifact` и `ListArtifacts`.

**SR:** SR-AGENT-ART-01, SR-AGENT-ART-02. gRPC: [[../gRPC/03 - Артефакты (Artifacts)]].

# 1. Список DTO

| **Название DTO** | **Назначение** |
| :--- | :--- |
| **CreateAgentArtifactRequest** | Запрос создания артефакта. |
| **AgentArtifactItem** | Read model артефакта. |
| **ListAgentArtifactsRequest** | Запрос списка с optional run filter. |
| **ListAgentArtifactsResponse** | Ответ: массив items. |

---

# DTO: CreateAgentArtifactRequest

## Контекст и назначение

Создание structured JSON payload, привязанного к конкретному run в thread. `kind` — application-defined type key (e.g. `card_draft`, `mining_result`).

**Назначение:** Запрос.
**gRPC:** [[../gRPC/03 - Артефакты (Artifacts)#grpc-CreateArtifact]].

## Структура данных

| **Имя поля (JSON)** | **Тип данных** | **Описание** |
| :--- | :--- | :--- |
| `thread_id` | `uuid` | Parent thread. |
| `run_id` | `uuid` | Run, к которому относится payload. |
| `kind` | `string` | Type discriminator. |
| `payload_json` | `string` | JSON document as string. |

## Пример работы (JSON)

```json
{
  "thread_id": "thread-uuid-001",
  "run_id": "run-uuid-001",
  "kind": "card_draft",
  "payload_json": "{\"Word\":\"slept\",\"Expression\":\"I slept well.\"}"
}
```

# DTO: AgentArtifactItem

## Контекст и назначение

Persisted artifact row для list/create responses.

**Назначение:** Ответ (сущность / элемент коллекции).
**Реализация сущности:** Таблица `agent_artifacts`.

## Структура данных

| **Имя поля (JSON)** | **Тип данных** | **Описание** |
| :--- | :--- | :--- |
| `id` | `uuid` | Artifact id. |
| `run_id` | `uuid` | Associated run. |
| `thread_id` | `uuid` | Associated thread. |
| `kind` | `string` | Type key. |
| `payload_json` | `string` | JSON payload. |
| `created_at` | `datetime` | UTC создания. |

## Пример работы (JSON)

```json
{
  "id": "art-uuid-001",
  "run_id": "run-uuid-001",
  "thread_id": "thread-uuid-001",
  "kind": "card_draft",
  "payload_json": "{\"Word\":\"slept\"}",
  "created_at": "2026-06-28T10:06:00Z"
}
```

# DTO: ListAgentArtifactsRequest

## Контекст и назначение

Запрос списка артефактов треда. Optional `run_id` сужает выборку одним run.

**Назначение:** Запрос.
**gRPC:** [[../gRPC/03 - Артефакты (Artifacts)#grpc-ListArtifacts]].

## Структура данных

| **Имя поля (JSON)** | **Тип данных** | **Описание** |
| :--- | :--- | :--- |
| `thread_id` | `uuid` | Тред. |
| `run_id` | `uuid \| null` | Optional filter. |

---

<span id="dto-ListAgentArtifactsResponse"></span>

# DTO: ListAgentArtifactsResponse

## Контекст и назначение

Ответ `ListArtifacts`: items отсортированы по `created_at` DESC.

**Назначение:** Ответ.

## Структура данных

| **Имя поля (JSON)** | **Тип данных** | **Описание** |
| :--- | :--- | :--- |
| `items` | `array<AgentArtifactItem>` | Артефакты треда. |

## Пример работы (JSON)

```json
{
  "items": [
    {
      "id": "art-uuid-001",
      "run_id": "run-uuid-001",
      "thread_id": "thread-uuid-001",
      "kind": "card_draft",
      "payload_json": "{\"Word\":\"slept\"}",
      "created_at": "2026-06-28T10:06:00Z"
    }
  ]
}
```
