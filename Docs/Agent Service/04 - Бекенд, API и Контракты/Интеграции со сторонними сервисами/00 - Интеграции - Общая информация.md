# Интеграции — Общая информация

Agent Service интегрируется с:

| Система | Протокол | Назначение | Документ |
| :--- | :--- | :--- | :--- |
| **VocabularyService** | gRPC (h2c) | Project access, analytics, AI mining | [[01 - Vocabulary Service (gRPC)]] |
| **OpenAI-compatible LLM** | HTTPS | Chat completions (explain, general) | [[02 - LLM Provider (OpenAI-compatible HTTP)]] |
| **PostgreSQL** | Npgsql | Agent persistence | folder `03` |

Нет Redis, RabbitMQ, outbound REST к third-party (translate/dictionary — на Aggregator).

## Configuration

| Section | Keys | Default |
| :--- | :--- | :--- |
| `Vocabulary` | `GrpcAddress` | `http://localhost:5117` |
| `Ai` | `BaseUrl`, `ApiKey`, `Model`, `TimeoutSeconds`, `Enabled` | см. [[02 - LLM Provider (OpenAI-compatible HTTP)]] |

Outbound gRPC metadata к Vocabulary: `user_id`, `roles` (comma-separated).

Детали: [[01 - Vocabulary Service (gRPC)]], [[02 - LLM Provider (OpenAI-compatible HTTP)]].
