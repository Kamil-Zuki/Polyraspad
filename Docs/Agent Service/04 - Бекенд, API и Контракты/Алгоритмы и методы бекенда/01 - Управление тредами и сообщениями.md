# Управление тредами и сообщениями

Класс: `AgentThreadService` (`AgentService/Services/AgentThreadService.cs`).

## ListThreads

1. `EnsureProjectAccessAsync(userId, projectId, roles)`.
2. Query `agent_threads` WHERE user_id, project_id, archived_at IS NULL.
3. ORDER BY updated_at DESC.
4. Map to list DTOs.

## CreateThread

1. Project access check.
2. Insert thread with new Guid, timestamps UTC.

## GetThread / ArchiveThread

Ownership filter `thread.user_id == userId`. Archive sets `archived_at`, updates `updated_at`.

## ListMessages

1. Verify thread ownership.
2. Clamp limit 1..100.
3. Optional cursor: messages with `created_at < beforeMessage.created_at`.
4. Take limit+1; set `next_before` if more exist.
5. Reverse collection for chronological UI order.

## CreateRun

1. Validate roles, categories, tool statuses.
2. Load thread; reject if archived or project mismatch.
3. **Transaction:** insert user + assistant messages, run (status completed), domain decision, tool calls.
4. Auto-derive thread title from first user content if empty.

## Artifacts

Create: verify thread + run belong together. List: filter by thread_id, optional run_id.
