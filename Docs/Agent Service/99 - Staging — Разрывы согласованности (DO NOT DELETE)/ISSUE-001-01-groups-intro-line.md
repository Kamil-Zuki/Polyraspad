# ISSUE-001: Группы 01 без intro-line «Ниже представлен перечень…»

## Тип

Пробел

## В двух словах

По правилам оформления групп `01` перед SR-таблицей в `## Возможности данного раздела` должна быть строка «Ниже представлен перечень…». Во всех 11 group-файлах Agent Service (01–11) эта строка отсутствовала.

## Где проблема

| Источник | Якорь | Что не сходится |
| :--- | :--- | :--- |
| 01 | `01 - Управление тредами` … `11 - Платформенные контракты` | Нет intro-line перед таблицей SR |
| Шаблон | `(Done) Authorization Service` / Aggregator etalon | Есть «Ниже представлен перечень функциональных требований (SR)…» |

Путь (вторично): `01 - Функциональная спецификация/Возможности сервиса/*.md` (кроме `00`)

## Рекомендуемое действие

Добавить одну строку intro перед каждой SR-таблицей; SR-блоки §1/§2/§3 в Agent уже в основном соответствуют шаблону.

## Статус

Resolved (2026-06-27) — повторный аудит: intro-line присутствует во всех 11 group-файлах; SR-блоки §1/§2/§3 и якоря `{#SR-*}` на месте.
