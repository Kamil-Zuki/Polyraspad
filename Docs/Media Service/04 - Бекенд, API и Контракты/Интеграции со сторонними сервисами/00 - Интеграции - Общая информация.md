# Введение

Настоящий документ описывает **внешние и платформенные интеграции** микросервиса Media Service.

Media Service **не** инициирует HTTP/gRPC к другим микросервисам — только **S3 API** к object storage (MinIO в dev). Входящие вызовы — **gRPC от Aggregator Service**, который валидирует JWT и передаёт `user_id` в metadata.

RabbitMQ и Redis **не используются**.

**SR:** SR-MEDIA-STORAGE-*, SR-MEDIA-BOOK-*, SR-MEDIA-COLL-*, SR-MEDIA-OPS-02.
