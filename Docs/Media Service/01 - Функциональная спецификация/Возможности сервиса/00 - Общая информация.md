## Введение

Настоящий документ определяет функциональные возможности (сервисные требования) микросервиса **«Media Service»** — внутреннего сервиса объектного хранилища и метаданных Reader Library платформы Polyraspad.

**Media Service** владеет бинарными медиа (image, audio, document) в S3-совместимом bucket и JSON-индексами личной библиотеки читателя. Публичный REST **не** экспонируется: клиенты обращаются к **Aggregator Service**, который проксирует gRPC и передаёт `user_id` в metadata.

Документ предназначен для разработчиков, QA, системных аналитиков и архитекторов.

# Группы возможностей

Ниже представлен перечень из 4 групп функциональных возможностей (сервисных требований) для микросервиса Media Service. Требования сгруппированы по логическим блокам для удобства навигации.

| Группа | Название и Описание |
| :----- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Загрузка и выдача медиа (Media Storage)** | **Object storage:** Upload image/audio/document в MinIO и резолв URL для клиента и server-fetch. |
| **Reader Library — книги (Reader Books)** | **Library books:** List, save и delete метаданных книг в project library. |
| **Reader Library — коллекции и шаринг (Reader Collections)** | **Collections & share:** CRUD коллекций, share/unshare collaborators и inbox shared collections. |
| **Платформенные контракты (Operations)** | **Platform ops:** Health-check, gRPC-only API и контекст `user_id` в metadata. |

---

## Описание возможностей

Ниже представлен детальный перечень сервисных требований (SR) для каждой группы. Подробное описание каждого требования находится в соответствующих вложенных документах.

### 1. Загрузка и выдача медиа (Media Storage)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-MEDIA-STORAGE-01** | **Upload image:** Сохранение image blob в bucket; лимит 5 MB, content-type `image/*`. |
| **SR-MEDIA-STORAGE-02** | **Upload audio:** Сохранение audio blob (TTS upload, audio fields). |
| **SR-MEDIA-STORAGE-03** | **Upload document:** PDF/EPUB/TXT в `documents/`; лимит 50 MB. |
| **SR-MEDIA-STORAGE-04** | **Get image URL:** Server-fetch или public URL по `image_id`. |
| **SR-MEDIA-STORAGE-05** | **Get audio URL:** URL по `audio_id`. |
| **SR-MEDIA-STORAGE-06** | **Get document URL:** URL по `document_id` для BFF proxy и Reader. |

### 2. Reader Library — книги (Reader Books)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-MEDIA-BOOK-01** | **List library books:** Список книг пользователя в `project_id`. |
| **SR-MEDIA-BOOK-02** | **Save library book:** Upsert метаданных книги (title, document link, progress, collection). |
| **SR-MEDIA-BOOK-03** | **Delete library book:** Удаление записи из JSON-индекса проекта. |

### 3. Reader Library — коллекции и шаринг (Reader Collections)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-MEDIA-COLL-01** | **List collections:** Коллекции owner в project с вложенными books. |
| **SR-MEDIA-COLL-02** | **Save collection:** Upsert коллекции и collaborators snapshot. |
| **SR-MEDIA-COLL-03** | **Delete collection:** Удаление коллекции; книги теряют `collection_id`. |
| **SR-MEDIA-COLL-04** | **Share collection:** Добавление collaborator к коллекции. |
| **SR-MEDIA-COLL-05** | **Unshare collection:** Удаление collaborator из коллекции. |
| **SR-MEDIA-COLL-06** | **List shared collections:** Inbox коллекций, расшаренных с текущим user. |

### 4. Платформенные контракты (Operations)

| Код | Название и Описание |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **SR-MEDIA-OPS-01** | **Health-check:** `GET /healthz` для оркестрации и CI. |
| **SR-MEDIA-OPS-02** | **gRPC identity context:** Обязательный `user_id` header для library RPC; без JWT внутри сервиса. |
