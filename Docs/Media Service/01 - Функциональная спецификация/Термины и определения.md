# Введение

Глоссарий терминов микросервиса **Media Service** и связанных компонентов Polyraspad (object storage, Reader Library, BFF).

| Термин | Описание |
| :--- | :--- |
| **Media Service** | gRPC-микросервис (:5121) для MinIO/S3 upload и метаданных Reader Library. |
| **Media Object** | Бинарный объект в bucket: `images/`, `audio/` или `documents/` + UUID. |
| **Reader Library** | Каталог книг пользователя в языковом project; метаданные в JSON-индексе S3. |
| **Reader Collection** | Подборка книг (reading list) с optional share к другим users. |
| **Collaborator** | Пользователь с доступом к shared collection (read/edit по `can_edit`). |
| **Public URL** | URL для браузера через `Storage:PublicBaseUrl` (например nginx → MinIO). |
| **Server-fetch URL** | URL для backend HttpClient (`ServerFetchBaseUrl`) — внутри Docker сети. |
| **Presigned URL** | Временная подписанная ссылка S3, если public base URL не задан. |
| **Aggregator (BFF)** | Публичный REST `/api/Media/*`; проксирует gRPC и выполняет TTS/extract/proxy локально. |
| **project_id** | Идентификатор языкового проекта из VocabularyService; сегмент пути JSON-индекса. |
| **user_id (gRPC header)** | UUID пользователя из JWT; Aggregator прокидывает в metadata — Media не парсит JWT. |

## Процессы

| Термин | Описание |
| :--- | :--- |
| **Library import** | Upload document → (BFF extract text) → save book record → Reader analyze terms. |
| **Share collection** | Owner добавляет collaborator; collaborator видит collection через `ListSharedReaderCollections`. |
| **CORS media proxy** | `serve-image` / `serve-document` на **Aggregator** — не часть Media Service. |
