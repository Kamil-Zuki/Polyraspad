# Введение

Глоссарий терминов микросервиса **Billing Service** и связанных компонентов SaaS-биллинга Polyraspad.

---

# Ключевые понятия

| Термин | Описание |
| :--- | :--- |
| **Billing Service** | Микросервис SaaS-тарифов: планы, подписки, entitlements, инвойсы. gRPC порт `5127`, PostgreSQL `billing_service`. |
| **SaaS Plan** | Тариф платформы (`free`, `pro`) с ценой и jsonb entitlements — не deck/marketplace product. |
| **BillingSubscription** | Подписка пользователя на SaaS plan; отдельна от deck subscription в VocabularyService. |
| **Customer (billing)** | Проекция `user_id` в billing DB; один customer на пользователя в v1. |
| **Entitlements** | Лимиты плана (`maxProjects`, `maxCards`, `aiRequestsPerDay`) — map string→string в proto. |
| **Provider-agnostic core** | Доменная логика через `IPaymentProvider`; ЮKassa — первый адаптер. |
| **LocallyManaged** | Подписка продлевается нашим `RenewalWorker` (ЮKassa без native subscription object). |
| **ProviderManaged** | Подписка синхронизируется webhooks провайдера (Stripe future). |
| **Grace period** | Дни после `PastDue` когда access ещё разрешён (`Billing:GracePeriodDays`, default 3). |
| **Processed webhook** | Idempotency record (`Provider` + `EventId`) — защита от replay. |
| **Aggregator BFF** | REST `/api/billing/*` и webhook ingress; forward в Billing gRPC. |

# Процессы

| Термин | Описание |
| :--- | :--- |
| **Checkout flow** | CreateCheckout → redirect URL → provider payment → webhook → Active subscription. |
| **Free plan fallback** | Без effective paid subscription access и entitlements = default plan (`free`). |
| **Normalized domain event** | PaymentSucceeded, PaymentFailed, … — единый вход для WebhookOrchestrator. |

# Отличие от marketplace

| Термин | Описание |
| :--- | :--- |
| **Deck subscription** | Подписка на published deck — `VocabularyService.SubscriptionService`, не Billing Service. |
| **Marketplace entitlement** | Покупка deck/product — `UserEntitlement` в Vocabulary; SaaS plan не заменяет deck purchase. |
