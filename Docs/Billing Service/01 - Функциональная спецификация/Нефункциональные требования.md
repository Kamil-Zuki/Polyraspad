# Введение

Нефункциональные требования к **Billing Service** — SaaS-биллингу Polyraspad.

---

# 1. Назначение документа

## 1.1 Цель

Зафиксировать ожидания по безопасности платежей, idempotency webhooks, доступности gRPC и деградации для downstream consumers.

## 1.2 Область

| Компонент | Область |
| :--- | :--- |
| BillingService (gRPC) | Access, subscriptions, webhooks processing |
| PostgreSQL `billing` | Персистентная проекция |
| RenewalWorker | Background recurring для LocallyManaged |
| AggregatorService | REST BFF (отдельная документация) |

---

# 2. Категории NFR

## 2.1 Безопасность

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| **NFR-BILL-001** | Не хранить PAN/CVV; только provider tokens и card masks. | Высокий |
| **NFR-BILL-002** | Webhook signature verification у провайдера перед apply events. | Высокий |
| **NFR-BILL-003** | BillingService не открыт наружу; webhooks ingress через Aggregator + optional shared key. | Высокий |

## 2.2 Надёжность

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| **NFR-BILL-004** | Webhook idempotency — composite PK `processed_webhooks`; duplicate → 200 без double-apply. | Высокий |
| **NFR-BILL-005** | VocabularyService при недоступности Billing — fail-open на free entitlements + log (product decision v1). | Средний |
| **NFR-BILL-006** | RenewalWorker isolated scope per poll; ошибка одной подписки не блокирует batch. | Средний |

## 2.3 Производительность

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| **NFR-BILL-007** | `GetEntitlements` p99 < 50 ms при warm DB (read-mostly, AsNoTracking). | Средний |
| **NFR-BILL-008** | Checkout создаёт outbound HTTP к провайдеру — timeout и retry на HttpClient policy. | Средний |

## 2.4 Эксплуатация

| ID | Требование | Приоритет |
