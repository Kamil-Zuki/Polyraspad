# Введение

Настоящий документ описывает **ключевые алгоритмы и методы** серверной реализации микросервиса **Billing Service** — логику за gRPC-контрактом, payment adapters и background worker.

Документ предназначен для backend-разработчиков, архитекторов и DevOps. Основан на **SR-BILL-*** из `01` и **КАР-*** из `02`.

gRPC-контракты — в [[../Методы API/gRPC/00 - gRPC - Общая информация|gRPC — Общая информация]]; здесь — **как** реализовано, со ссылками на `#grpc-*`.
