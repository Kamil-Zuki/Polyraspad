# Введение

Настоящий документ содержит описание **исходящих и входящих интеграций** микросервиса **Billing Service** с внешними payment API и внутренними микросервисами платформы Polyraspad.

Billing Service **не** принимает browser traffic напрямую: REST BFF — **AggregatorService**; entitlement reads — **VocabularyService**. Единственный внешний HTTP — **ЮKassa API** (checkout, recurring, webhook parsing).

Документ разработан на основе SR из `01` и КАР из `02`.

---

# 1. Список интеграций

| Интеграция | Код требования | Протокол | Назначение |
| :--- | :--- | :--- | :--- |
| **ЮKassa (HTTP/REST)** | SR-BILL-PROV-02 | HTTPS REST | Checkout, recurring payments, webhook payload mapping; LocallyManaged mode. |
| **Mock provider (in-process)** | SR-BILL-PROV-03 | In-process | Dev/tests без credentials; programmatic success path. |
| **AggregatorService (gRPC client → Billing gRPC server)** | SR-AGG-BILL-01, SR-AGG-BILL-02 | gRPC h2c | REST proxy для JWT-пользователя; webhook ingress. |
| **VocabularyService (gRPC client → Billing gRPC server)** | SR-BILL-ENT-01 | gRPC h2c | `GetEntitlements` для enforcement лимитов. |

**Inbound webhooks:** ЮKassa → public Aggregator URL → `#grpc-ProcessWebhook`. Billing не имеет публичного HTTP endpoint для webhooks.
